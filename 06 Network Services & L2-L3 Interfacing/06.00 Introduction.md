# Section 6: Network Services & L2-L3 Interfacing

This section covers the protocols that glue Layer 2 and Layer 3 together and the services
that make networks usable: address resolution, DHCP, NAT/PAT, hop-by-hop tracing, Linux
routing with iptables, and IEEE 802.11 wireless access.

##  Topic Index
- [[06.01 Address Resolution Protocol (ARP) Deep Dive]] — Study the L3-to-L2 ARP transaction lifecycle, broadcast requests, unicast replies, and CAM tables.
- [[06.02 Hop-by-Hop Packet Tracing (L2 MAC vs L3 IP Rewrites)]] — The exam trace-table pattern: IP addresses never change, MAC addresses rewrite at every router hop.
- [[06.03 Dynamic Host Configuration Protocol (DHCP) Full Architecture]] — DORA, UDP 67/68, T1/T2 timers, ICMP ping and gratuitous ARP conflict checks, broadcast flag, relay agents, and disk persistence.
- [[06.04 Network Address Translation (NAT) & Port Address Translation (PAT)]] — Translation profiles (Static, Dynamic, PAT), the four Cisco NAT address definitions, full CLI configuration, and port forwarding vs. triggering.
- [[06.05 Linux Routing, Tools & iptables DMZ Forwarding]] — `route -n`, `netstat -rn`, `traceroute`, and the iptables MASQUERADE / DNAT rules for outbound access and DMZ publishing.
- [[06.06 IEEE 802.11 Wireless Architecture (CSMA-CA, IFS, DSSS)]] — CSMA/CD vs. CSMA/CA, the SIFS/PIFS/DIFS hierarchy, NAV and RTS/CTS hidden-node handling, and the DSSS Barker sequence.
