# 06.6. Mathematical Morphology, Cellular Counting, and Zhang-Suen Thinning (TP2 Part 3)

## 1. Overview
This note covers morphological operations (erosion, dilation, opening, closing), erythrocyte (red blood cell) segmentation on `Globules_rouges.jpg`, and Zhang-Suen skeletonization, covering Exercise 4 of TP2.

## 2. Erythrocyte Segmentation Pipeline

```python
import cv2
import numpy as np

# Load red blood cell image in grayscale
im1 = cv2.imread("Images/Globules_rouges.jpg", cv2.IMREAD_GRAYSCALE)
if im1 is None:
    raise FileNotFoundError("File 'Images/Globules_rouges.jpg' not found.")

# Binarize with Otsu's thresholding
_, imb1 = cv2.threshold(im1, 0, 255, cv2.THRESH_BINARY_INV + cv2.THRESH_OTSU)

# 1. Evaluate Structuring Elements across Sizes
se_3 = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
se_5 = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
se_7 = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (7, 7))

# Opening breaks thin bridges connecting adjacent cells
opened_cells = cv2.morphologyEx(imb1, cv2.MORPH_OPEN, se_5)

# 2. Cell Counting via Connected Components
num_labels, labels, stats, centroids = cv2.connectedComponentsWithStats(opened_cells)
# Subtract 1 to exclude the background label
total_cells = num_labels - 1
print(f"Total Erythrocytes Counted: {total_cells}")

# 3. Zhang-Suen Skeletonization (Thinning)
# Requires opencv-contrib-python
skeleton = cv2.ximgproc.thinning(opened_cells, thinningType=cv2.ximgproc.THINNING_ZHANGSUEN)
cv2.imwrite("Images/Globules_skeleton.jpg", skeleton)
```
