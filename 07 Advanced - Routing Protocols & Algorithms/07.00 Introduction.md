# Section 7: Advanced - Routing Protocols & Algorithms

This section covers dynamic routing: how a router processes packets, the static-vs-dynamic
design trade-off, and the three protocol families — distance-vector (RIPv2), link-state
(OSPF + Dijkstra), and path-vector (BGP).

- [[07.01 IP Router Operations & Packet Processing]] — Trace the physical, link, and network layer processing of a packet arriving on a router interface.
- [[07.02 Static vs. Dynamic Routing Paradigms]] — Evaluate resource utilization, security profiles, and scalability constraints of both approaches.
- [[07.03 Distance Vector Protocols & RIPv2]] — Bellman-Ford mechanics, loop prevention (split horizon, poison reverse, hold-down), RIPv1 vs. RIPv2, IOS configuration, and the route-update processing rules with a worked walkthrough.
- [[07.04 Link-State Routing, Multi-Area OSPF & Dijkstra]] — LSDB synchronization, multi-area design and router roles, cost metrics and the gigabit bottleneck, plus a complete Dijkstra SPF worked example.
