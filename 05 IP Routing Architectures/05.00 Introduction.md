# Section 5: IP Routing Architectures (Core Routing Principles)

This section covers the mechanics of the routing table itself: entry anatomy, path selection
rules, static and default routes, and the two diagnostic skills exams love — spotting
inconsistent routing tables and reconstructing topologies from `show ip route`.
Dynamic routing *protocol* implementations (RIPv2, OSPF, BGP, Dijkstra) live in Section 07.

##  Topic Index
- [[05.01 Route Entries & Administrative Distance]] — Understand routing table entry anatomy (protocol codes, metrics, uptime), administrative distance hierarchies, and longest prefix matching.
- [[05.02 Longest Prefix Match (LPM) Evaluation Order]] — Trace step-by-step binary lookup matching for CIDR routing decisions and the /32 → /0 specificity order.
- [[05.03 Static & Default Routing Mechanics]] — Master next-hop routing, directly attached static routes, default routes (gateway of last resort), and floating static backup paths.
- [[05.04 Routing Table Inconsistency Detection]] — Identify the four classic misconfiguration patterns that make a routing table invalid, with the full TD 2 worked table.
- [[05.05 Reverse-Engineering Network Topologies]] — Reconstruct physical and logical topologies from `show ip route` output, with the TD 2 graded reconstruction.
