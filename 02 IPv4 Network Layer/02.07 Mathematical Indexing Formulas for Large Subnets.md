### 2.7 Mathematical Indexing Formulas for Large Subnets (Dr. Djerbi's Method)

When a Class A network is subnetted so heavily that the borrowed bits **span two octets**, listing
subnets in a table becomes impossible (hundreds or thousands of rows). Dr. Djerbi's retake
examinations (26.02.2023) test a pure algebraic method: a formula that maps a subnet **index $N$**
directly to its address, and back.

#### Reference Problem (Retake 26.02.2023)

> Network `125.0.0.0` (Class A) is divided into **1020 subnets** (so at least 1020 are required).

**Step 1 — Borrowed bits:**
$$2^n \ge 1020 \implies n = 10 \text{ bits} \quad (2^{10} = 1024 \text{ subnets})$$

**Step 2 — New mask:**
$$\text{Prefix} = 8 + 10 = \mathbf{/18} \implies \text{mask } \mathbf{255.255.192.0}$$
$$h = 32 - 18 = 14 \text{ host bits} \implies 2^{14} - 2 = 16{,}382 \text{ usable hosts per subnet}$$

**Step 3 — Where the 10 subnet bits live:**
* **Second octet $Y$:** all **8** borrowed bits' "high" portion $\implies$ $Y$ takes any value $0$–$255$.
* **Third octet $Z$:** the remaining **2** bits $\implies$ block size $\Delta = 256 - 192 = \mathbf{64}$,
  so $Z \in \{0, 64, 128, 192\}$.
* The fourth octet $T$ is always part of the host portion: $T = 0$ at every subnet base.

#### The Indexing Formulas

With the address written as $X.Y.Z.T$ (subnet base addresses always have $T = 0$):

$$\boxed{X = 125 \qquad N = 4Y + \frac{Z}{64} \qquad T = 0}$$

**Index $\to$ Address (extract the subnet of index $N$, 0-indexed):**
$$Y = \left\lfloor \frac{N}{4} \right\rfloor \qquad\qquad Z = (N \bmod 4) \times 64$$

**Address $\to$ Index (identify which subnet an address belongs to):**
$$N = 4Y + \frac{Z}{64}$$

*Why the factor 4?* The third octet cycles through its **4** legal values $\{0, 64, 128, 192\}$
before the second octet $Y$ increments by one. So one full step of $Y$ covers 4 subnets.

#### Worked Examples (from the official graded solution)

| Task | Computation | Result |
| :--- | :--- | :--- |
| **45th subnet ($N=45$)** | $Y = \lfloor 45/4 \rfloor = 11$; $Z = (45 \bmod 4) \times 64 = 64$ | `125.11.64.0` |
| **59th subnet ($N=59$)** | $Y = \lfloor 59/4 \rfloor = 14$; $Z = (59 \bmod 4) \times 64 = 192$ | `125.14.192.0` |
| **13th subnet ($N=13$)** | $Y = 3$; $Z = 64$ $\implies$ subnet `125.3.64.0` | first machine `125.3.64.1` |
| **18th subnet ($N=18$)** | $Y = 4$; $Z = 128$ $\implies$ subnet `125.4.128.0` | last machine `125.4.191.254` |
| **37th subnet ($N=37$)** | $Y = 9$; $Z = 64$ $\implies$ subnet `125.9.64.0` | broadcast `125.9.127.255` |
| **Subnet 70 ($N=70$)** | $Y = 17$; $Z = 128$ | `125.17.128.0`, bcast `125.17.191.255` |
| **Subnet 71 ($N=71$)** | $Y = 17$; $Z = 192$ | `125.17.192.0`, bcast `125.17.255.255` |
| **Index of `125.16.64.0`** | $N = 4(16) + 64/64 = 64 + 1$ | subnet **65** |
| **Index of `125.20.192.0`** | $N = 4(20) + 192/64 = 80 + 3$ | subnet **83** |

#### Validity Test — Does a Subnet Exist?

A candidate base address is a real subnet **only if $Z$ is a legal multiple of the block size**:

> **Does `125.16.98.0` exist?** **No.** $Z = 98$ is **not a multiple of 64**
> ($98 \notin \{0, 64, 128, 192\}$). Valid third octets for this mask are only
> $0, 64, 128, 192$. The address `125.16.98.x` falls *inside* subnet `125.16.64.0/18`
> (as a host address), but `125.16.98.0` is **not a subnet boundary** and cannot be the
> "first machine" of anything.

#### Edge Cases from the Same Exam

* **Last installable subnet:** index $1023$ (all 10 subnet bits = 1) $\implies$
  $Y = 255$, $Z = 192$ $\implies$ `125.255.192.0`, broadcast `125.255.255.255`.
* **Locating a host:** host `125.44.192.11` $\implies$ subnet base `125.44.192.0` (since
  $Z = 192$ is legal) $\implies$ host offset $= 11$ $\implies$ **11th machine** of that subnet;
  subnet broadcast `125.44.255.255`.
* **Last machine of subnet `125.4.128.0`:** the subnet spans `125.4.128.0` – `125.4.191.255`
  $\implies$ last usable = `125.4.191.254` (broadcast minus one).

#### Generalizing the Formulas

For any Class A base $X.0.0.0/8$ subnetted with $n$ borrowed bits where the last borrowed bits
occupy the third octet with mask value $M_3$ in that octet:

$$\text{Block size } \Delta = 256 - M_3 \qquad \text{Subnets per } Y\text{-step} = \frac{256}{\Delta} = k$$

$$\boxed{N = k \cdot Y + \frac{Z}{\Delta}} \qquad \boxed{Y = \left\lfloor \frac{N}{k} \right\rfloor, \quad Z = (N \bmod k) \times \Delta}$$

| Mask in 3rd octet ($M_3$) | $\Delta = 256 - M_3$ | Legal $Z$ values | $k$ (per $Y$ step) | Formula |
| :---: | :---: | :---: | :---: | :--- |
| 192 | 64 | 0, 64, 128, 192 | 4 | $N = 4Y + Z/64$ |
| 224 | 32 | 0, 32, 64, ..., 224 | 8 | $N = 8Y + Z/32$ |
| 240 | 16 | 0, 16, ..., 240 | 16 | $N = 16Y + Z/16$ |
| 248 | 8 | 0, 8, ..., 248 | 32 | $N = 32Y + Z/8$ |

The same logic extends one octet further for Class B bases (bits spanning the 3rd and 4th octets).
