## 2. Ingestion and Scanline Manipulation (Exercise 2)

```python
import cv2
import numpy as np

# Ingest test image
img = cv2.imread("Images/BoatsColor.bmp")
if img is None:
    raise FileNotFoundError("Image file 'Images/BoatsColor.bmp' not found.")

# Inspect image dimensions
height, width, channels = img.shape
print(f"Loaded image: Height={height}px, Width={width}px, Channels={channels}")

# Access pixel value at row y=100, column x=150
b_val, g_val, r_val = img[100, 150]
print(f"Pixel at (100, 150): Blue={b_val}, Green={g_val}, Red={r_val}")

# Set center horizontal line to red (BGR: [0, 0, 255])
modified_img = img.copy()
center_row = height // 2
for col in range(width):
    modified_img[center_row, col] = [0, 0, 255]

cv2.imwrite("Images/BoatsColor_red_centerline.bmp", modified_img)
```

## 3. Fixed Binary Thresholding (Exercise 3)
Binary thresholding segments an image into foreground and background regions based on intensity:

$$\text{Output}(y, x) = \begin{cases} 255 & \text{if } I_{\text{gray}}(y, x) > T \\ 0 & \text{if } I_{\text{gray}}(y, x) \le T \end{cases}$$

Here, we binarize `counter.jpg` using a fixed threshold $T = 80$, comparing an OpenCV implementation with a custom NumPy function:

```python
import cv2
import numpy as np

def manual_threshold(gray_img: np.ndarray, thresh: int = 80) -> np.ndarray:
    """Applies binary thresholding using vectorized NumPy operations."""
    binary_out = np.zeros_like(gray_img)
    binary_out[gray_img > thresh] = 255
    return binary_out

# Ingest in grayscale mode
counter_gray = cv2.imread("Images/counter.jpg", cv2.IMREAD_GRAYSCALE)
if counter_gray is None:
    raise FileNotFoundError("Image 'Images/counter.jpg' could not be loaded.")

# 1. OpenCV implementation
_, imgb1 = cv2.threshold(counter_gray, thresh=80, maxval=255, type=cv2.THRESH_BINARY)

# 2. Custom implementation
imgb2 = manual_threshold(counter_gray, thresh=80)

# Verify that both methods produce identical matrices
assert np.array_equal(imgb1, imgb2), "Implementations mismatch."
print(f"Thresholding verification passed. Active foreground pixels: {(imgb1 == 255).sum():,}")

cv2.imwrite("Images/imgb1.jpg", imgb1)
```
