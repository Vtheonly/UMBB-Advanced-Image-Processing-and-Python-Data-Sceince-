# 02.10. Code Modularity, Packaging, and Standard Library Systems

## 1. Overview
Modular programming organizes code into reusable modules and packages. This note covers import semantics, the role of `__init__.py`, the `if __name__ == '__main__'` entry point, and key Python standard library modules (`math`, `random`, `datetime`, `statistics`, `os`).

## 2. Code Modularity: Modules and Packages
- **Module**: A single Python file (`.py`) containing executable code, functions, and classes.
- **Package**: A directory containing modules alongside an `__init__.py` file, which marks the folder as an importable Python package.

```text
my_analytics_package/
│
├── __init__.py           # Package initializer
├── data_cleaning.py      # Cleaning submodule
└── math_metrics.py       # Metrics submodule
```

```python
# Content of my_analytics_package/__init__.py
from .data_cleaning import clean_text
from .math_metrics import compute_mean

__all__ = ['clean_text', 'compute_mean']
```

### The Role of `__name__ == "__main__"`
When a file runs directly from the terminal (`python file.py`), CPython assigns the string `"__main__"` to the built-in variable `__name__`. If the file is imported by another module (`import file`), `__name__` is set to the file's module name instead.
This mechanism lets a module include standalone executable code (such as self-tests or CLI scripts) that won't run when the module is imported elsewhere:

```python
def calculate_bmi(weight: float, height: float) -> float:
    return weight / (height ** 2)

if __name__ == "__main__":
    # Runs during standalone script execution, skipped on import
    print("Self-test:", calculate_bmi(75, 1.80))
```

## 3. Core Standard Library Modules for Data Science

### `math` Module
Provides basic mathematical functions implemented on C doubles:
```python
import math
sqrt_val = math.sqrt(16)        # 4.0
log_val = math.log10(100)       # 2.0
exp_val = math.exp(2)           # 7.389...
rounded = math.ceil(4.2)        # 5 (Round up)
floored = math.floor(4.8)       # 4 (Round down)
```

### `random` Module
Provides pseudo-random number generators using the Mersenne Twister algorithm:
```python
import random
random.seed(42)                 # Guarantees reproducibility
int_val = random.randint(1, 10) # Random integer in range [1, 10]
float_val = random.uniform(10, 20)
sampled = random.sample([1, 2, 3, 4, 5], 3) # Sampling without replacement
```

### `datetime` Module
Provides classes for manipulating dates, times, and intervals:
```python
import datetime
now = datetime.datetime.now()
current_date = datetime.date.today()
delta = datetime.date(2026, 10, 1) - datetime.date(2026, 9, 1)
print(f"Days between: {delta.days}")  # 30 days
```

### `statistics` Module
Provides basic statistical calculations on Python iterables:
```python
import statistics
vals = [10, 12, 15, 15, 18, 20, 25]
mean_val = statistics.mean(vals)
median_val = statistics.median(vals)
stdev_val = statistics.stdev(vals)
```

### `os` Module
Provides portable operating system interfaces:
```python
import os
current_dir = os.getcwd()
os.makedirs("data/processed", exist_ok=True)
exists = os.path.exists("data/raw/data.txt")
```
