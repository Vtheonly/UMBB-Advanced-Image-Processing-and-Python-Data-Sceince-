## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Brighten by 50 | `np.clip(np.round(img.astype(np.float64) + 50), 0, 255).astype(np.uint8)` | `img + 50` | Modulo wrap: verified 240+50 -> 44 (not 255) — solarization on paper. |
| Window radius | `rad = ksize // 2` | `rad = ksize / 2` | Float radius -> slicing `img[y-rad:y+rad+1]` raises `TypeError` (slices demand ints). |
| AWGN | `noise = np.random.normal(0.0, sigma, img.shape)` then add on floats | `np.random.normal(0, sigma, img.shape)` added straight onto uint8 | uint8 addition wraps; also `normal`'s 3rd arg is a TUPLE shape (see [[04.5. NumPy Math Engine, Broadcasting Rules & Axis Reductions]]). |
| Salt & pepper | `rnd = np.random.rand(*img.shape[:2])`; threshold at `p/2` and `1 - p/2` | `np.random.randint` for the mask | The canonical form compares a uniform `[0,1)` draw against p/2 slices. |
| Padding | `padded = np.pad(img.astype(np.float64), rad, mode='reflect')` | `mode='constant'` zero-padding | Zero rims create phantom dark halos behind smoothing kernels. |
| Integral image | `ii[1:, 1:] = np.cumsum(np.cumsum(padded, axis=0), axis=1)` | manual double loop over the DP recurrence | Correct but O(HW) in Python loops — the two-cumsum line IS the DP recurrence, vectorized. |
| Box filter (library) | `cv2.blur(img, (k, k))` | `cv2.blur(img, k)` | ksize is a TUPLE for blur/Gaussian/box, unlike median's int. |
| Gaussian | `cv2.GaussianBlur(img, (k, k), sigmaX)` | `cv2.GaussianBlur(img, k, sigma)` | Same tuple rule; sigmaX is the third positional. |

## 3. Trap Deep-Dives

### 3.1 The Float-to-Int Defensive Sandwich (Invariant 3)
Three stages, memorized as a single chained line:
```python
out = np.clip(np.round(img.astype(np.float64) OP arg), 0, 255).astype(np.uint8)
```
Stage 1 upcasts (uint8 arithmetic is modulo: 240+50 = 44, verified); stage 2 computes in float64 (signed negatives preserved, fractions kept); stage 3 clamps-then-rounds-then-casts. Every noise-injection, subtraction, convolution, or metric question starts with stage 1 on paper. (Saturated `cv2.add` is the legal alternative for pure blending — but NEVER for metric math, where clipping signed errors destroys the MSE.)

### 3.2 Radius Discipline: ksize // 2
Odd kernels $K = 2k+1$ need $k = K//2$. With `/` the value is a float (5/2 = 2.5) and slice bounds reject it. Verified pairing: `(5 // 2, type(5 / 2).__name__) -> (2, 'float')`. Write `//` on every radius computation; add the comment "integer floor".

### 3.3 The Two Noise Generators (write them from scratch)
```python
def add_gaussian_noise(img, mean=0.0, variance=100.0):
    sigma = np.sqrt(variance)                       # variance -> sigma conversion!
    noise = np.random.normal(mean, sigma, img.shape)
    noisy = img.astype(np.float64) + noise
    return np.clip(noisy, 0, 255).astype(np.uint8)

def add_salt_pepper(img, p=0.10):
    noisy = img.copy()
    rnd = np.random.rand(*img.shape[:2])
    noisy[rnd < p / 2.0] = 255                       # salt
    noisy[rnd > 1.0 - p / 2.0] = 0                  # pepper
    return noisy
```
Note the variance-to-sigma square root (the #1 parametric slip) and the symmetric thresholds p/2 around 0 and 1-p/2 around 1.

### 3.4 Integral Image in One Line, Window Sums in O(1)
```python
padded = np.pad(f64_img, rad, mode="reflect")
ii = np.zeros((padded.shape[0] + 1, padded.shape[1] + 1))
ii[1:, 1:] = np.cumsum(np.cumsum(padded, axis=0), axis=1)   # +1 border of zeros
# window (y..y+K, x..x+K) in the padded frame:
s = ii[y+K, x+K] + ii[y, x] - ii[y, x+K] - ii[y+K, x]       # D + A - B - C
mean = s / (K * K)
```
The leading zero row/column absorbs the `y-1`/`x-1` of the classic formula — no boundary guards needed. Verified: the four-corner difference returns the exact window sum.

## 5. Exam Question Archetypes

**Archetype — from-scratch 3x3 mean filter:** "Implement an unweighted 3x3 box filter from scratch using reflection padding and nested loops."
```python
def mean_filter(img, ksize=3):
    rad = ksize // 2                                   # integer radius
    src = img.astype(np.float64)
    padded = np.pad(src, rad, mode="reflect")
    out = np.zeros_like(src)
    for y in range(img.shape[0]):
        for x in range(img.shape[1]):
            win = padded[y:y + ksize, x:x + ksize]     # [y, x] slicing
            out[y, x] = win.sum() / (ksize ** 2)
    return np.clip(np.round(out), 0, 255).astype(np.uint8)
```

**Archetype — O(1) box filtering:** the integral-image block of Section 3.4 plus the loop `for y ... for x ...: s = ii[y+K, x+K] + ii[y, x] - ii[y, x+K] - ii[y+K, x]; out[y, x] = round(s / K**2)`.

## 6. Self-Audit Checklist
