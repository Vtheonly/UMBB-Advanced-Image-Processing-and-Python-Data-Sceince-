# 04.5. NumPy Math Engine, Broadcasting Rules & Axis Reductions

> Exam-defense companion to [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules]]. The parent note derives broadcasting right-to-left; this sheet drills the exam-day instant recall: axis direction, maximum vs. max, the (3,) vs (4,) broadcast trap, stacking brackets, random-range exclusivity, and the FFT dB pipeline. All traps verified on NumPy 2.1.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Per-column means | `np.mean(m, axis=0)` | — | `axis=0` collapses **rows** (vertical traversal, one value per column). |
| Per-row means | `np.mean(m, axis=1)` | — | `axis=1` collapses **columns** (horizontal traversal, one value per row). |
| Element-wise maximum | `np.maximum(a, b)` | confusing with `np.max(a)` | `np.maximum` is a **binary ufunc** (two arrays, shape kept); `np.max`/`a.max()` is a **reduction** (one array -> scalar/axis vector). |
| Row-vector broadcast | `matrix + vec` with `vec.shape == (3,)` | `vec.shape == (4,)` against `(4, 3)` | `(3,)` aligns to rows (works); `(4,)` aligns to columns (crashes: `operands could not be broadcast together`). |
| Column broadcast | `vec[:, None]` or `vec.reshape(4, 1)` | `vec` alone | `(4, 1)` broadcasts down columns of `(4, 3)`; bare `(4,)` does not. |
| Vertical stack | `np.vstack([a, b])` | `np.vstack(a, b)` | The inputs travel inside ONE list (a tuple also works; loose arrays raise). |
| Uniform ints | `np.random.randint(0, 21)` for grades in [0, 20] | `np.random.randint(0, 20)` | High bound is **exclusive** — the second form can never produce 20. |
| Loose-int random | `np.random.rand(h, w)` | `np.random.rand((h, w))` | `rand` takes unpacked integers; a tuple crashes. |
| Tuple-shape random | `np.random.normal(0, sigma, (h, w))` | `np.random.normal(0, sigma, h, w)` | `normal` takes a single shape argument — extra positional args raise. |

## 2. Exact Signatures and Positional Defaults

```python
np.mean(a, axis=None)          # None -> single scalar over the whole array
np.max(a, axis=1)              # reduction; np.maximum(a, b) is element-wise
np.maximum(a, b)                # ufunc: pairwise max, broadcastable shapes
np.clip(a, lo, hi)             # fused maximum+minimum against constants
np.vstack([a, b])              # list bracket
np.hstack((a, b))              # tuple also legal - WRITE the bracket either way
np.random.randint(low, high_exclusive, size)
np.random.rand(d0, d1, ...)     # loose ints, uniform [0, 1)
np.random.randn(d0, d1)         # loose ints, standard normal
np.random.normal(mean, sigma, shape_tuple)
np.fft.fft2(img)               # 2D DFT
np.fft.fftshift(spectrum)      # center DC term
20 * np.log10(np.abs(spectrum) + 1e-8)   # dB magnitude, epsilon-guarded
```

## 3. Trap Deep-Dives

### 3.1 Axis Directionality (the vertical/horizontal recall)
For `m` of shape (2, 3):
- `np.mean(m, axis=0)` -> `[25., 35., 45.]` — one mean **per column**; the operation walks *down* the rows and collapses them.
- `np.mean(m, axis=1)` -> `[20., 50.]` — one mean **per row**; walks *across* the columns and collapses them.

Channel-wise image mean: a color image `(H, W, 3)` reduced with `axis=2` yields one mean per pixel; `axis=(0, 1)` yields three channel means.

### 3.2 Broadcasting's Right-to-Left Alignment
Shapes align from the **trailing** dimension. `(4, 3) + (3,)` works because the 3 matches the trailing 3 and the missing leading dimension is treated as 1. `(4, 3) + (4,)` fails: 4 wants to match 3. The repair is an explicit column: `vec.reshape(4, 1)` or `vec[:, None]` — the written exam's favorite "add a 1D bias to every row/column" question.

### 3.3 Random-Generator Boundary Discipline
`randint`'s high is exclusive — to sample grades 0..20 inclusive write `randint(0, 21)`. Salt-and-pepper thresholds compare `rand()` against `p/2` and `1 - p/2` (see [[19.5. Spatial Restoration, Integral Fast Filtering & Noise Generators]]). And remember the two signatures: `rand/randn` take **loose integers**, `normal/uniform/integers` take **a shape tuple**. Mixing them is the classic paper crash.

### 3.4 The FFT dB Pipeline (order matters)
```python
spectrum = np.fft.fftshift(np.fft.fft2(img.astype(np.float64)))
magnitude_db = 20 * np.log10(np.abs(spectrum) + 1e-8)
```
`fftshift` **after** `fft2`; the `+ 1e-8` guards `log10(0)` at the DC bin. Forgetting the epsilon crashes with a divide warning and `-inf` pixels; forgetting the shift puts DC in a corner.

## 5. Exam Question Archetypes

**Archetype 1 — channel means, no loops:** "Calculate the channel-wise mean of an RGB image tensor without loops."
```python
channel_means = np.mean(img, axis=(0, 1))    # (3,) BGR averages
```

**Archetype 2 — row bias:** "Add a 1D bias vector `b` of length 4 to every row of a `(4, 3)`... " — careful: a length-4 vector is a *column* bias. For a length-3 row bias, `M + b` suffices; for length 4, write `M + b.reshape(4, 1)` or `M + b[:, None]`.

**Archetype 3 — spectrum:** "Display the log-magnitude spectrum of a grayscale image." The Section 3.4 pipeline, then `ax.imshow(magnitude_db, cmap='gray')`.

## 6. Self-Audit Checklist
