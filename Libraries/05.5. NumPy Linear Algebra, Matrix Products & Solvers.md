# 05.5. NumPy Linear Algebra, Matrix Products & Solvers

> Exam-defense companion to [[05. NumPy Linear Algebra and Advanced Numerical Computation]]. The parent note tabulates `np.linalg`; this sheet carries the operator traps: `@` vs `*`, `solve` vs `inv`, and the `.T` attribute. Verified on NumPy 2.1.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Matrix product | `A @ B` or `np.dot(A, B)` | `A * B` | `*` is the **Hadamard** (element-wise) product. With square matrices it silently computes a *wrong* number — no exception. |
| Transpose | `A.T` | `A.T()` | `TypeError` — `.T` is an attribute (a strided view), not a method. |
| System solve | `np.linalg.solve(A, b)` | `np.linalg.inv(A) @ b` | Runs, but is numerically weaker (explicit inverse amplifies round-off) and is the form examiners penalize. |
| Determinant | `np.linalg.det(A)` | `np.det(A)` | No such top-level function; it lives under `np.linalg`. |
| Rank | `np.linalg.matrix_rank(A)` | `np.rank(A)` | `np.rank` is a legacy alias for `ndim` — completely different quantity. |
| Norm | `np.linalg.norm(x)` | — | L2 by default. |

## 2. Exact Signatures and Positional Defaults

```python
C = A @ B                       # matrix product; inner dims must match
H = A * B                       # element-wise (Hadamard) - different operator!
A_T = A.T                       # attribute, no parentheses
np.linalg.det(A)                # |A|
np.linalg.inv(A)                # A^-1 (existence requires det != 0)
np.linalg.solve(A, b)           # x in Ax = b via LU decomposition
np.linalg.norm(x)               # Euclidean L2; norm(x, axis=...) for rows
np.linalg.eig(A)                # eigenvalues, eigenvectors
np.linalg.matrix_rank(A)
np.trace(A)                     # top-level, NOT under linalg
```

## 3. Trap Deep-Dives

### 3.1 The Star Operator's Two Jobs
`A * B` multiplies element by element; `A @ B` contracts rows into columns. For diagonal matrices the two coincide by accident, which makes the bug survive casual checking. On paper, label the intent in a comment whenever both interpretations are plausible:
```python
cov = X_c.T @ X_c        # Gram matrix: matrix product
elem = X * mask          # element-wise suppression
```

### 3.2 Solve, Don't Invert
The written exam's "Solve $Ax = b$" wants `np.linalg.solve(A, b)` — the LU-based solver. Building `np.linalg.inv(A) @ b` does compute the same mathematical answer (verified equal here for a well-conditioned 2x2) but costs more and is graded as the inferior pattern: the inverse path squares the condition number's damage. Only invert when the inverse itself is the deliverable.

### 3.3 `.T` Is a View Attribute
`A.T` (and `A.T @ b`) is correct; `A.T()` raises `TypeError: 'tuple' object is not callable`. The same attribute-vs-method rule as `.shape` — see [[01.5. NumPy Instantiation, Types & Memory Safeguards]].

### 3.4 Norms Without Loops
`np.linalg.norm(x)` equals `np.sqrt(np.sum(x ** 2))` element-for-element (verified). Write the library call; keep the manual expansion in a comment as the definition of the metric you are computing.

## 4. Motor-Recall Code Templates

```python
import numpy as np
A = np.array([[2.0, 1.0], [1.0, 3.0]])
b = np.array([8.0, 14.0])
x = np.linalg.solve(A, b)        # [2., 4.] - LU solve, NOT inv @ b
M = A @ A.T                      # product; A.T is an attribute
det = np.linalg.det(A)
rank = np.linalg.matrix_rank(A)
```

## 5. Exam Question Archetypes

**Archetype — linear system:** "Solve the system 2x + y = 8, x + 3y = 14 for x in Python."
```python
A = np.array([[2.0, 1.0], [1.0, 3.0]])
b = np.array([8.0, 14.0])
x, y = np.linalg.solve(A, b)    # x = 2.0, y = 4.0
```

## 6. Self-Audit Checklist

- [ ] Every matrix product uses `@` (or `np.dot`); `*` reserved for element-wise and annotated.
- [ ] `.T` never carries parentheses.
- [ ] Systems solved with `np.linalg.solve`, never `inv(...) @ ...`.
- [ ] `det`, `inv`, `solve`, `norm`, `matrix_rank`, `eig` all read as `np.linalg.f`; only `trace` sits at top level.
- [ ] Inner-dimension compatibility stated before writing any `@`.
