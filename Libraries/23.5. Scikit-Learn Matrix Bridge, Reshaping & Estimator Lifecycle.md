# 23.5. Scikit-Learn Matrix Bridge, Reshaping & Estimator Lifecycle

> Exam-defense companion to [[23. Scikit-Learn Primitives - Clustering, Dimensionality, and Metrics]]. Verified on scikit-learn (current sandbox build): the 3D-crash, the Series-crash, and the reshape bridge all reproduce exactly as claimed.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Fit on an image | `X = img.reshape((-1, 3))` then `kmeans.fit_predict(X)` | `kmeans.fit(img)` | `ValueError: Found array with dim 3. Estimator expected <= 2` (verified) — estimators demand 2D `(n_samples, n_features)`. |
| Single feature column | `scaler.fit(df[['Age']])` | `scaler.fit(df['Age'])` | `ValueError: Expected a 2-dimensional container but got Series` (verified) — double brackets. |
| Split order | `X_train, X_test, y_train, y_test = train_test_split(X, y, ...)` | any other order | Alternating X/y, train/test — a swapped pair trains on targets. |
| Test scaling | `scaler.transform(X_test)` | `scaler.fit_transform(X_test)` | Data leakage: test statistics enter the model; examiners flag it instantly. |
| Mask overlap metric | `jaccard_score(gt.ravel(), pred.ravel())` | `jaccard_score(gt, pred)` on 2D | 2D arrays make the metric think you passed multi-label data — flatten first. |
| KMeans reproducibility | `KMeans(n_clusters=3, random_state=42, n_init='auto')` | bare `KMeans(3)` | Unseeded, un-pinned initialization: irreproducible segmentation. |
| Label back-mapping | `labels.reshape((h, w))` | `labels.reshape(h * w)` left flat | The label vector must return to the 2D image grid for display/evaluation. |

## 3. Trap Deep-Dives

### 3.1 The 2D Matrix Contract
Scikit-Learn estimators validate `(n_samples, n_features)`. Images are `(H, W, C)`; tabular single columns are Series. Both are rejected (verified messages above). The two legal bridges:
- **Image bridge:** `X = img.reshape((-1, c)).astype(np.float32)` — the `-1` wildcard flattens H x W; channel depth stays as features. Verified: `(8, 8, 3) -> (64, 3)`.
- **Column bridge:** `df[['Age']]` — the double bracket produces `(n, 1)`.

### 3.2 The Estimator Lifecycle (fit / transform / predict / fit_transform)
Estimators are STATEFUL objects: `fit` learns parameters ($\mu, \sigma$, centroids) and stores them inside the instance; `transform`/`predict` apply the learned parameters. `fit_transform` fuses both. The lifecycle discipline:
```python
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)   # learn from TRAIN only
X_test_s  = scaler.transform(X_test)        # apply frozen parameters
```
Calling `fit_transform` on the test partition recomputes statistics from test data — leakage. Same rule for imputers (`SimpleImputer`) and every encoder.

### 3.3 train_test_split's Alternating Order
The return order is `X_train, X_test, y_train, y_test` — X-block first, train-then-test inside each. Write the four names in exactly that order and annotate. `test_size=0.2` + `random_state=42` are the standard pair; `stratify=y` preserves class proportions (classification questions).

### 3.4 The Complete Segmentation Round-Trip
```python
h, w, c = img.shape
X = img.reshape((-1, c)).astype(np.float32)          # (H*W, 3)
km = KMeans(n_clusters=3, random_state=42, n_init="auto")
labels = km.fit_predict(X)                            # (H*W,)
segmented = labels.reshape((h, w))                    # back to the image grid
```
Verified end-to-end: `(8, 8, 3) -> (64, 3) -> (64,) -> (8, 8)`. The float32 cast prevents uint8 overflow inside squared-distance accumulations.

### 3.5 Jaccard on Flattened Masks
`jaccard_score` treats 2D arrays as multi-label indicator matrices. Segmentation evaluation flattens BOTH masks: `jaccard_score(gt.ravel(), pred.ravel())` — verified 0.667 on the reference pair. For multi-class label maps, flatten plus `average='macro'` (or `average=None` for per-class).

## 6. Self-Audit Checklist

- [ ] No 3D tensor or 1D Series passed into any estimator (reshape / double brackets).
- [ ] Split unpacked in the alternating order, with a comment naming each quarter.
- [ ] Train: `fit_transform`; Test: `transform` — never re-fit on test.
- [ ] `random_state` fixed on KMeans and split; `n_init` pinned.
- [ ] Masks flattened before `jaccard_score`.
