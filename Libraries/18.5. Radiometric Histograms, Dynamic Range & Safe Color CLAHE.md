# 18.5. Radiometric Histograms, Dynamic Range & Safe Color CLAHE

> Exam-defense companion to [[18. Visual Frequency and Radiometry - Histograms, Equalization, AHE, and CLAHE]]. The I-C-M-B-R bracket rule, the exclusive 256, the grayscale constraint, and the two-step CLAHE factory. Verified on OpenCV 4.13.0.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Histogram | `cv2.calcHist([img], [0], None, [256], [0, 256])` | `cv2.calcHist(img, 0, None, 256, 0, 256)` (unwrapped) | The five parameters are **lists** (four of them) and `None`; loose scalars fail the binding. |
| Histogram range | `[0, 256]` | `[0, 255]` | Upper bound is **exclusive** — 255 would drop the level-255 bin. |
| NumPy histogram | `np.bincount(img.ravel(), minlength=256)` | `np.bincount(img)` on 2D | bincount is 1D-only — `ravel()` first (verified equal to calcHist). |
| Global equalization | `cv2.equalizeHist(gray)` | `cv2.equalizeHist(color)` | Runtime error (assertion): equalizeHist accepts **single-channel 8-bit** only (verified). |
| CLAHE | `clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))` then `out = clahe.apply(l)` | one call chained blindly past the apply | Two-step factory: construct the object, then `.apply()`. |
| Color contrast | equalize L in LAB, recombine, convert back | equalizing B, G, R independently | Per-channel equalization destroys color balance (three different transfer functions). |
| Normalization | `cv2.normalize(img, None, 0, 255, cv2.NORM_MINMAX)` | `cv2.normalize(img, 0, 255)` positional | The `dst=None` slot sits between; keyword form is the safe spelling. |

## 3. Trap Deep-Dives

### 3.1 I-C-M-B-R — the calcHist bracket mnemonic
**I**mages, **C**hannels, **M**ask, **B**ins, **R**anges: `[img]`, `[0]`, `None`, `[256]`, `[0, 256]`. Everything list-bracketed EXCEPT the mask. Color histograms per channel: three calls with channels `[0]`, `[1]`, `[2]` (B, G, R order — see [[15.5. OpenCV Matrix Topology, Saturated Math & BGR Conventions]]).

### 3.2 The 256 Boundary
Levels are 0..255 but the range tuple is `[0, 256]` — exclusive upper edge, exactly like `randint` high and `arange` stop. Writing `[0, 255]` silently loses the last bin. One family, one rule: bin edges and stop bounds are half-open.

### 3.3 The Grayscale Constraint
`cv2.equalizeHist` validates single-channel input; a 3-channel frame dies at the C++ assertion (verified). CLAHE's `.apply()` enforces the same. Hence the safe color pipeline below.

### 3.4 The Safe Color CLAHE Pipeline (memorize as five lines)
```python
lab = cv2.cvtColor(bgr, cv2.COLOR_BGR2LAB)          # 1. perceptual space
l, a, b = cv2.split(lab)                            # 2. isolate luminance
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))   # 3. factory
l_eq = clahe.apply(l)                                # 4. equalize L only
out = cv2.cvtColor(cv2.merge([l_eq, a, b]), cv2.COLOR_LAB2BGR)  # 5. recombine
```
Luminance carries contrast; a/b carry color — untouched. Equalizing channels independently applies three different intensity maps and shifts every hue. (Why LAB: see [[15. OpenCV Core Architecture - Matrix Representation, Channels, and Color Constellations]].)

### 3.5 clipLimit and Tiles
`clipLimit` (default 40.0; typical 2.0-4.0) caps each tile histogram bin; the excess is redistributed uniformly — that is the "contrast limited" that stops noise amplification. `tileGridSize=(8, 8)` sets the contextual grid; bilinear interpolation between tiles hides the seams.

## 4. Motor-Recall Code Templates

```python
import cv2, numpy as np
h = cv2.calcHist([gray], [0], None, [256], [0, 256]).ravel()   # I-C-M-B-R
pmf = h / h.sum()                                               # probabilities
cdf = pmf.cumsum()                                              # CDF for equalization
clahe = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
l_eq = clahe.apply(l)                                           # two-step factory
```

## 5. Exam Question Archetypes

**Archetype — equalize a color photograph safely:** "Write a function to equalize the contrast of a color BGR photograph without altering its color balance." The five-line LAB pipeline of Section 3.4 is the complete answer — equalize L only, recombine, convert back.

**Archetype — manual equalization:** "Given the 256-bin histogram, derive the transfer function." $s_k = \text{round}((K-1)\, \text{CDF}(k))$ with $K = 256$ — theory in [[01.9. Tonal Histograms, Probability Densities, and Cumulative Distribution Functions]].
