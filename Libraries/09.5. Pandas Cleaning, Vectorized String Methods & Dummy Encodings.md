# 09.5. Pandas Cleaning, Vectorized String Methods & Dummy Encodings

> Exam-defense companion to [[09. Pandas Data Cleansing - Handling Nulls, Deduplication, and String Normalization]]. This is the densest Pandas trap sheet in the family: instance-method vs. top-level taxonomy, the in-place None trap, the `.str` accessor, drop-axis defaults, rename keywords, and dummy encoding. Verified on pandas 2.2.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Drop null rows | `df = df.dropna()` | `pd.dropna(df)` | `AttributeError` — module `pandas` has no function `dropna`; it is an instance method. |
| Fill nulls | `df['Age'] = df['Age'].fillna(median)` | `pd.fillna(...)` | Same module/method confusion. |
| One-hot encode | `pd.get_dummies(df, columns=['Sex'], drop_first=True, dtype=int)` | `df.get_dummies()` | `AttributeError` — get_dummies is a **top-level factory function**, never a frame method. |
| In-place cleaning | `df.dropna(inplace=True)` (no assignment) | `df = df.dropna(inplace=True)` | The statement sets `df = None` — every following line dies with `AttributeError: 'NoneType'`. |
| Lowercase a column | `df['City'].str.lower()` | `df['City'].lower()` | `AttributeError` — plain strings have `.lower`, but a Series exposes it only through the `.str` accessor. |
| Drop a column | `df.drop(columns=['Bonus'])` | `df.drop('Bonus')` | `KeyError` — `drop` defaults to ROW (axis=0) labels. `df.drop('Bonus', axis=1)` is the equivalent long form. |
| Rename columns | `df.rename(columns={'old': 'new'})` | `df.rename({'old': 'new'})` | Without `columns=`, the dict maps **index** labels — columns silently unchanged (verified). |
| Deduplicate | `df.drop_duplicates(subset=['PatientID'], keep='last')` | `df.unique()` | `.unique()` exists only on a Series, not the frame. |

## 2. Exact Signatures and Positional Defaults

```python
df = df.dropna()                          # reassignment STANDARD (never inplace+assign)
df = df.dropna(subset=["Age"])            # null-check only these columns
df["Age"] = df["Age"].fillna(df["Age"].median())   # median imputation
df["City"] = df["City"].str.strip().str.lower()     # chained .str ops
df = df.drop(columns=["Bonus"])           # columns= keyword, axis-safe
df = df.rename(columns={"Salary": "MonthlySalary"})
enc = pd.get_dummies(df, columns=["Gender"], drop_first=True, dtype=int)
dups = df.duplicated()                    # boolean Series (keep='first' default)
```

## 3. Trap Deep-Dives

### 3.1 The Two-Way Taxonomy
- **Instance methods only** (called on the object): `dropna`, `fillna`, `drop`, `drop_duplicates`, `rename`, `sort_values`, `groupby`, `duplicated`, `query`.
- **Top-level functions only** (called on `pd.`): `get_dummies`, `concat`, `merge`, `to_datetime`, `to_numeric`, `date_range`, `crosstab`, `cut`, `qcut`.
Crossing either direction is an `AttributeError`. The top-level family continues in [[12.5. Pandas Relational Joins, Merging Logic & Concat Axes]] and [[14.5. Pandas Temporal Mechanics, DatetimeIndex & Rolling Windows]].

### 3.2 The Fatal In-Place Assignment
`dropna(inplace=True)` performs the mutation and **returns `None`**. Assigned, it nulls the whole variable. The vault's own convention (Decision 5 of the companion architecture): **write reassignment, never `inplace=True`** — one uniform `target = transformation(source)` mental model. (The vault's tutorial notes do use bare `inplace=True` without assignment, which runs — the *combination* with assignment is what destroys data.)

### 3.3 The .str Accessor Is Mandatory
Every vectorized string operation on a Series travels through `.str`: `.str.strip()`, `.str.lower()`, `.str.replace(a, b)`, `.str.contains(pat)`, `.str.split(',')`. Chains read left to right: `df['City'].str.strip().str.title()`. Calling `.lower()` directly on the Series is the blueprint's exact "phantom method" moment. (Temporal twin: `.dt` — see [[14.5. Pandas Temporal Mechanics, DatetimeIndex & Rolling Windows]].)

### 3.4 The Dummy-Variable Trap (drop_first)
One-hot encoding a K-level categorical emits K columns that sum to 1 — perfect multicollinearity for linear models (the dummy-variable trap). `drop_first=True` emits K-1; the dropped level becomes the reference encoded by all-zeros. `dtype=int` materializes 0/1 integers instead of booleans (models and exams both prefer it).

### 3.5 Drop's Silent Axis
`df.drop('Bonus')` looks up `'Bonus'` among ROW labels and raises `KeyError` — not a helpful "axis" hint. The `columns=[...]` keyword makes intent explicit and survives grader scrutiny; `axis=1` is accepted but visually ambiguous on paper.

## 5. Exam Question Archetypes

**Archetype — the standard cleaning triple:** "Impute missing ages with the median, standardize text in the City column, and one-hot encode gender."
```python
df["Age"] = df["Age"].fillna(df["Age"].median())
df["City"] = df["City"].str.strip().str.title()
df = pd.get_dummies(df, columns=["Gender"], drop_first=True, dtype=int)
```

**Archetype — spot the bug:** `df = df.dropna(inplace=True)` — sets `df` to `None`. Correct: `df = df.dropna()`.

## 6. Self-Audit Checklist

- [ ] No `pd.dropna(df)` / `pd.fillna(...)` / `df.get_dummies()` crossings in either direction.
- [ ] No `inplace=True` anywhere; the reassignment pattern is uniform.
- [ ] Every Series string method is prefixed `.str`.
- [ ] Every column drop says `columns=[...]` (or explicit `axis=1`).
- [ ] Every `rename` passes `columns=`.
- [ ] `get_dummies` carries `drop_first=True` (+ `dtype=int`) unless the question demands all levels.
