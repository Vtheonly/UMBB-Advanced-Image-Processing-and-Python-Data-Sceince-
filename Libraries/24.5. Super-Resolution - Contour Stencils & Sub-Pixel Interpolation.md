## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Output grid | `out = np.zeros((2*h - 1, 2*w - 1))` | `(2*h, 2*w)` | Factor-2 Getreuer scaling maps H rows to 2H-1: even coordinates hold originals, odd coordinates hold interpolants. (2H would leave an unfilled rim.) |
| Sample placement | `out[2*y, 2*x] = lr[y, x]` | `out[y, x] = lr[y, x]` | Known pixels go to EVEN grid coordinates only. |
| Center computation | TV comparison of the two diagonals, then average the LOWER-variation pair | averaging all four corners unconditionally | Unconditional averaging = plain bilinear behavior — exactly the blur contour stencils exist to avoid. |
| TV values | `tv1 = abs(v00 - v11)`, `tv2 = abs(v10 - v01)` | swapped corners | Swapping picks the WRONG diagonal — the edge-adaptivity inverts. |
| Tie case | average of all four corners | picking either pair silently | The tie is a stated branch of the algorithm. |
| Final cast | `np.clip(np.round(out), 0, 255).astype(np.uint8)` | skipping round | Truncation instead of rounding biases every interpolant downward. |

## 2. The Cell Geometry and Formulas

A 2x2 LR cell has four known corners; the missing points are the center X and the four edge midpoints N, S, W, E:

```text
v(0,0) -------- N -------- v(0,1)
  |                          |
  W            X             E
  |                          |
v(1,0) -------- S -------- v(1,1)
```

- $\text{TV}_1 = |v_{0,0} - v_{1,1}|$ (main diagonal)
- $\text{TV}_2 = |v_{1,0} - v_{0,1}|$ (anti-diagonal)
- $X = \tfrac{1}{2}(v_{0,0} + v_{1,1})$ if $\text{TV}_1 < \text{TV}_2$; $X = \tfrac{1}{2}(v_{1,0} + v_{0,1})$ if $\text{TV}_2 < \text{TV}_1$; $X = \tfrac{1}{4}(\text{sum of all four})$ if tied.
- Edge midpoints: average of the two neighboring known/interpolated samples along that edge (horizontal midpoints from left-right neighbors, vertical midpoints from top-bottom).

## 3. Trap Deep-Dives

### 3.1 Why (2H-1, 2W-1)
Between H original samples there are H-1 gaps; factor-2 interpolation fills each gap with one new sample: total $H + (H-1) = 2H - 1$. Verified placement: `out[2*y, 2*x] = lr[y, x]` for every y, x — index 2y never exceeds 2H-2. Allocating (2H, 2W) leaves an unexplained zero rim that breaks PSNR comparisons against reference outputs.

### 3.2 Interpolating ALONG the Edge (the core idea)
Total variation is small along a contour (intensity nearly constant) and large across it. Averaging the corners of the LOW-TV diagonal interpolates along the estimated contour — sharp; averaging the high-TV diagonal crosses the edge — blurred. The stencil choice is a per-cell edge-orientation estimate, computed from nothing but two absolute differences.

### 3.3 The Worked 2x2 Example (verified)
$[120, 140; 100, 180]$: $\text{TV}_1 = |120 - 180| = 60$; $\text{TV}_2 = |100 - 140| = 40$. $\text{TV}_2 < \text{TV}_1$, so $X = \tfrac{1}{2}(100 + 140) = 120$ — the anti-diagonal pair carries the "flat" direction. Write the two TV numbers explicitly; graders award the comparison logic.

### 3.4 Midpoint Averaging Order
Centers are computed FIRST (they need only original corners); midpoints SECOND (they may average an original and an already-computed center). The parent implementation interpolates even/odd coordinate positions in two separate passes — mirror that order to avoid using values that do not exist yet.

## 4. Motor-Recall Code Templates

```python
import numpy as np
h, w = lr.shape
out = np.zeros((2 * h - 1, 2 * w - 1), dtype=np.float64)
for y in range(h):
    for x in range(w):
        out[2 * y, 2 * x] = lr[y, x]              # originals at even coords
for y in range(h - 1):
    for x in range(w - 1):
        v00, v01 = float(lr[y, x]), float(lr[y, x + 1])
        v10, v11 = float(lr[y + 1, x]), float(lr[y + 1, x + 1])
        if abs(v00 - v11) < abs(v10 - v01):        # TV1 < TV2
            out[2*y + 1, 2*x + 1] = 0.5 * (v00 + v11)
        elif abs(v10 - v01) < abs(v00 - v11):      # TV2 < TV1
            out[2*y + 1, 2*x + 1] = 0.5 * (v10 + v01)
        else:                                       # tie
            out[2*y + 1, 2*x + 1] = 0.25 * (v00 + v01 + v10 + v11)
# ... then edge midpoints by neighbor averaging ...
result = np.clip(np.round(out), 0, 255).astype(np.uint8)
```

## 5. Exam Question Archetypes

**Archetype — the hand computation:** "Given a 2x2 pixel cell [120, 140; 100, 180], calculate the interpolated center intensity using Contour Stencils."
$\text{TV}_1 = 60$, $\text{TV}_2 = 40$; the anti-diagonal wins; $X = (100 + 140)/2 = \mathbf{120}$.

**Archetype — grid sizing:** "An LR image of 100x200 is upscaled 2x by contour stencils. What is the output grid?" $(2 \cdot 100 - 1) \times (2 \cdot 200 - 1) = 199 \times 399$.
