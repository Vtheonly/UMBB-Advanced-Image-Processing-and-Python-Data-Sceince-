# 08.5. Pandas Indexing Mechanics, loc-iloc Bounds & Query Syntax

> Exam-defense companion to [[08. Pandas Indexing, Slicing, and Query Mechanics (loc, iloc, query, at)]]. The single highest-frequency Pandas exam error in the vault family is the loc/iloc boundary conflict. Verified on pandas 2.2.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Label slice | `df.loc['A':'C']` | — | **Includes** `'C'`: 3 rows for A, B, C. |
| Position slice | `df.iloc[0:2]` | — | **Excludes** 2: 2 rows (0, 1). Python slice semantics. |
| Scalar by label | `df.at['row_a', 'Age']` | `df.loc[['row_a'], ['Age']]` for a scalar | `.at` is the scalar fast path; returns the value, not a frame. |
| Scalar by position | `df.iat[0, 1]` | — | Fastest scalar accessor. |
| Compound filter | `df[(df['A'] > 5) & (df['B'] < 10)]` | `df[df['A'] > 5 & df['B'] < 10]` | `ValueError` (ambiguous truth) — `&` outranks `>`; parenthesize every clause. Also never `and`/`or` — they are the Python scalar keywords. |
| String filter | `df.query('A > 5 and B < 10')` | — | Inside the query *string*, `and`/`or` ARE legal (a mini-language). |
| Masked retention | `df.where(cond)` | — | Keeps the frame's shape; `NaN` where False — it never drops rows. |
| Index reset | `df.reset_index(drop=True)` | `df.reset_index()` expecting a clean RangeIndex | `drop=False` (default) converts old labels into a new `index` column. |

## 2. Exact Signatures and Positional Defaults

```python
rows = df.loc["row_a":"row_b", ["Name", "Age"]]   # label slice, INCLUSIVE stop
rows = df.iloc[0:2, 0:2]                           # position slice, EXCLUSIVE stop
val  = df.at["row_a", "Age"]                       # scalar by label
val  = df.iat[0, 1]                                # scalar by position
mask = (df["Age"] > 25) & (df["City"] == "Algiers")
sub  = df.loc[mask, ["City", "Cost"]]              # boolean mask + column projection
q    = df.query('Age > 25 and City == "Algiers"')
kept = df.where(df["Age"] > 25)                    # same shape, NaN elsewhere
clean = df.reset_index(drop=True)                  # discard old labels
```

## 3. Trap Deep-Dives

### 3.1 The Boundary Inclusivity Conflict
`.loc['A':'C']` returns A, B, C. `.iloc[0:2]` returns rows 0 and 1. Label-slicing is closed; position-slicing is half-open — exactly the same duality as `linspace` vs `arange` (see [[01.5. NumPy Instantiation, Types & Memory Safeguards]]). Write a boundary annotation (`# inclusive` / `# exclusive`) next to every slice on paper; graders look for it.

### 3.2 Boolean Filter vs. Query String — Two Grammars
The frame-level mask uses **bitwise** `&`/`|`/`~` with mandatory parentheses. The `.query()` mini-language uses Python `and`/`or` inside a quoted string. Crossing them is the classic paper error: `df[df('A') > 5 and ...]` is doubly wrong (call + wrong operator).

### 3.3 where() Does Not Drop
`df.where(cond)` answers "what survived, aligned to the original rows?" — output keeps every row, replacing False positions with `NaN`. If the question asks to *remove* rows, boolean masking (or `dropna` after `where`) is the instrument — see [[09.5. Pandas Cleaning, Vectorized String Methods & Dummy Encodings]].

### 3.4 reset_index(drop=...) Semantics
`drop=True` throws the old labels away; `drop=False` (default) *preserves them as a column* and assigns a fresh `RangeIndex`. Picking the wrong flag either leaks a junk `index` column or destroys labels you needed.

## 4. Motor-Recall Code Templates

```python
sub = df.loc[mask, ["City", "Cost"]]     # rows by mask, columns by list - one .loc call
neuro = df.loc[(df["Age"] > 45) & (df["Dept"] == "Neurology"), ["City", "Cost"]]
q = df.query('Age > 45 and Dept == "Neurology"')
first_two = df.iloc[0:2]                  # EXCLUDES row 2
a_to_c = df.loc["A":"C"]                  # INCLUDES C
```

## 5. Exam Question Archetypes

**Archetype — combined filter + projection:** "Filter patients older than 45 in the Neurology department and extract their City and Cost columns using `.loc`."
```python
result = df.loc[(df["Age"] > 45) & (df["Dept"] == "Neurology"), ["City", "Cost"]]
```

**Archetype — boundary pop-quiz:** "How many rows does `df.iloc[0:2]` return? And `df.loc['A':'C']`?"
Two (positions 0, 1 — stop excluded) and three (labels A, B, C — stop included).

## 6. Self-Audit Checklist

- [ ] Every `.loc` slice annotated inclusive; every `.iloc` slice annotated exclusive.
- [ ] Every compound mask: parentheses per clause, `&`/`|` only.
- [ ] Query strings quoted, with `and`/`or` only inside them.
- [ ] `.where` used for shape-preserving masking, never for row dropping.
- [ ] `reset_index` flag chosen deliberately (`drop=True` vs the default column-keeping).
