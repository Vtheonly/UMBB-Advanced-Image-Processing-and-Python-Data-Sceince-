# 15.5. OpenCV Matrix Topology, Saturated Math & BGR Conventions

> Exam-defense companion to [[15. OpenCV Core Architecture - Matrix Representation, Channels, and Color Constellations]]. This sheet encodes the Anti-Object Rule, the None-check, saturated vs. modulo arithmetic, and the threshold tuple return. All verified on OpenCV 4.13.0.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Color conversion | `gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)` | `img.cvtColor(...)` / `cv2.convertColor(...)` | `AttributeError` — images are raw ndarrays; OpenCV attaches NO methods to them. `convertColor` is contracted to `cvtColor`. |
| Loading check | `if img is None:` | `if img == None:` | `ValueError` (ambiguous truth) — the array comparison returns an array, not a boolean. `is` checks identity, always safe. |
| Brightening | `cv2.add(img, 40)` or float sandwich | `img + 40` | NumPy modulo: 250+20 wraps to 14. OpenCV saturates: 255. |
| Binarization | `_, mask = cv2.threshold(g, 127, 255, cv2.THRESH_BINARY)` | `bin = cv2.threshold(...)` single name | `bin` becomes the TUPLE `(retval, dst)` — every later image op on it fails. |
| Channel split | `b, g, r = cv2.split(img)` | — | Returns THREE 2D planes; order strictly B, G, R. |
| Channel merge | `cv2.merge((b, g, r))` | — | Takes a tuple/list of equal-shaped planes. |
| Grayscale read | `img = cv2.imread(f, 0)` | `cv2.imread(f)` expecting gray | Default flag is 1 (BGR color). The integer shorthand 0 = IMREAD_GRAYSCALE. |
| Failed load | `img is None` | try/except around imread | imread returns None instead of raising — try/except never fires (verified). |

## 2. Exact Signatures and Positional Defaults

```python
img = cv2.imread("file.bmp", cv2.IMREAD_GRAYSCALE)   # flags: 1 BGR, 0 GRAY, -1 UNCHANGED
gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
rgb  = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)
b, g, r = cv2.split(img)
img2 = cv2.merge((b, g, r))
bright = cv2.add(img, np.array([40], dtype=np.uint8))   # saturated
dark   = cv2.subtract(img, np.array([40], dtype=np.uint8))
ret, dst = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
cv2.imshow("win", img); cv2.waitKey(0); cv2.destroyAllWindows()
cv2.imwrite("out.bmp", img)
```

## 3. Trap Deep-Dives

### 3.1 The Anti-Object Rule
OpenCV never attaches domain methods to image arrays. Every algorithm is a free function in the `cv2` namespace taking the image as FIRST argument: `cv2.cvtColor(img, ...)`, `cv2.threshold(img, ...)`, `cv2.resize(img, ...)`, `cv2.equalizeHist(img)`. Your linguistic instinct invents `img.threshold()` or `cv2.crop()` — both AttributeError / missing (verified).

### 3.2 imread Fails as None — Silently
A bad path or unsupported codec returns `None`; no exception is raised. The canonical guard:
```python
img = cv2.imread(path, 0)
if img is None:
    raise FileNotFoundError(f"could not be opened: {path}")
```
`is None` (identity) — never `== None` (element-wise -> ambiguous-truth ValueError on multi-pixel arrays, verified).

### 3.3 Saturated vs. Modulo Arithmetic (the two number lines)
- NumPy on uint8: `250 + 20 = 14` (270 mod 256), `10 - 30 = 236` (-20 mod 256) — wrap-around.
- `cv2.add`: 255 (clamp high); `cv2.subtract`: 0 (clamp low).
- Float64 sandwich: `np.clip(np.round(f64_result), 0, 255).astype(np.uint8)` — the general instrument for restoration math (metrics must NOT use saturated ops: clipping signed errors destroys MSE — see [[22.5. Objective Metrics - MSE, PSNR, SSIM & Zero-Division Defense]]).

### 3.4 The threshold Tuple Return
`cv2.threshold` returns `(retval, dst)`. For fixed types `retval == thresh`; for Otsu (`cv2.THRESH_OTSU` + a pass-through 0) it carries the COMPUTED optimal threshold — the value the question usually asks for. Discard with `_` or keep, but always unpack two names.

### 3.5 BGR — the Historical Default
Load order is B, G, R: `img[100, 150]` is `[B, G, R]`; pure red to write is `(0, 0, 255)`; matplotlib needs `COLOR_BGR2RGB` first (see [[03.5. Matplotlib Canvas, Colormaps & Dual API Disambiguation]]). Grayscale conversion is BT.601: `Y = 0.299R + 0.587G + 0.114B`.

## 5. Exam Question Archetypes

**Archetype — the load/green/red pipeline:** "Load an image from disk, verify it loaded successfully, extract the green channel, and draw a pure red scanline across the middle."
```python
img = cv2.imread("photo.bmp")
if img is None: raise FileNotFoundError("photo.bmp")
b, g, r = cv2.split(img)                 # green channel = g (plane 1)
annotated = img.copy()
annotated[img.shape[0] // 2, :] = (0, 0, 255)   # BGR red
```

**Archetype — arithmetic pop-quiz:** "What is `uint8(250) + uint8(20)` in NumPy vs. `cv2.add`?" — 14 (modulo wrap) vs. 255 (saturated clamp).
