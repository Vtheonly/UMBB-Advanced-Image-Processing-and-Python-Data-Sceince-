# 10.5. Matplotlib & Seaborn Tabular Distribution Plotting Signatures

> Exam-defense companion to [[10. Matplotlib and Seaborn Statistical Plotting for Tabular Data]]. Seaborn's DataFrame-first signatures are easy to half-remember; this sheet pins them. Verified with seaborn 0.13.2 / matplotlib (Agg).

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Distribution | `sns.histplot(data=df, x='Salary', kde=True, bins=20, ax=ax)` | `sns.histplot(df['Salary'].values, kde=...)` for a tabular question | Works on arrays but loses the DataFrame idiom graders expect; the keyword form is the canonical signature. |
| Category spread | `sns.boxplot(data=df, x='Dept', y='Salary', ax=ax)` | `sns.boxplot(x=df['Dept'], y=df['Salary'])` | Both run; the `data=` + string-columns form is the one to write on paper (shorter, no mismatched-axes risk). |
| Density | `sns.violinplot(data=df, x='Dept', y='Salary', ax=ax)` | — | Same signature family as boxplot. |
| Correlation | `sns.heatmap(df.corr(), annot=True, fmt='.2f', cmap='Blues', square=True, ax=ax)` | `sns.heatmap(df.corr())` bare | Runs, but the exam answer wants annotation formatting. |
| Tonal histogram | `ax.hist(img.ravel(), bins=256, range=(0, 256), density=True)` | `ax.hist(img, bins=256)` on a 2D array | 2D input is a list-of-rows of varying length — wrong histogram; `ravel()` first. |
| 3D surface | `fig.add_subplot(111, projection='3d')` then `ax.plot_surface(X, Y, Z, cmap='viridis')` | `plt.subplots()` then `plot_surface` | A normal Axes has no `plot_surface`; the projection must be declared at creation. |
| Grid coordinates | `X, Y = np.meshgrid(x, y)` | `plot_surface(x, y, Z)` with 1D vectors | `plot_surface` demands 2D coordinate matrices. |

## 2. Exact Signatures and Positional Defaults

```python
sns.histplot(data=df, x="Salary", kde=True, bins=20, ax=ax)
sns.boxplot(data=df, x="Department", y="Salary", ax=ax)
sns.violinplot(data=df, x="Department", y="Salary", ax=ax)
sns.heatmap(corr, annot=True, fmt=".2f", cmap="Blues", square=True, ax=ax)

```

The `ax=` keyword on every Seaborn call is what makes it cooperate with your `plt.subplots` grid instead of opening its own figure — write it whenever a figure was created first.

## 3. Trap Deep-Dives

### 3.1 Seaborn's Data-First Grammar
Seaborn plotting functions take `data=df` plus **column-name strings** for `x`/`y`/`hue`. Passing Series objects also works but is longer and invites axis-name mismatch. On paper, the data-plus-string form is the gradable canonical.

### 3.2 fmt='.2f' Belongs to heatmap, not to annot
`annot=True` prints values; `fmt=".2f"` formats them. Omitting fmt with float correlations prints machine-precision noise across the matrix.

### 3.3 The Image Histogram Is an Axes Histogram
The tonal PDF of an 8-bit image is `ax.hist(img.ravel(), bins=256, range=(0, 256), density=True)`. `ravel()` flattens, `bins=256` gives one bin per gray level, `range=(0, 256)` keeps the exclusive upper edge consistent with the intensity domain (values 0..255 all land in bins), and `density=True` normalizes area to 1 (the empirical PDF). The OpenCV counterpart and the full PMF/CDF theory: [[18.5. Radiometric Histograms, Dynamic Range & Safe Color CLAHE]] and [[06.1.9. Tonal Histograms, Probability Densities, and Cumulative Distribution Functions]].

### 3.4 3D Needs the Projection at Creation
`fig.add_subplot(111, projection='3d')` (or `subplot_kw={'projection': '3d'}` into `plt.subplots`) — you cannot morph an existing 2D Axes. Coordinates must be `meshgrid` matrices.

import seaborn as sns, matplotlib.pyplot as plt
fig, ax = plt.subplots(figsize=(7, 4))

## 6. Self-Audit Checklist

- [ ] Every Seaborn call uses `data=df` + string column names, and carries `ax=` when a grid exists.
- [ ] `heatmap` pairs `annot=True` with `fmt=".2f"`.
- [ ] Image histograms start from `img.ravel()`.
- [ ] 3D plots declared with `projection='3d'` and `meshgrid` coordinates.
- [ ] Panel titles use `ax.set_title` (the set- rule of [[03.5. Matplotlib Canvas, Colormaps & Dual API Disambiguation]]).
