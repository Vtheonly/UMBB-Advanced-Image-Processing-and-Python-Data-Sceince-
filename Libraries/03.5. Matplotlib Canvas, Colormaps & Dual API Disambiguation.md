# 03.5. Matplotlib Canvas, Colormaps & Dual API Disambiguation

> Exam-defense companion to [[03. Matplotlib Core Architecture - Figure, Axes, and Canvas Visualization Mechanics]]. The parent note explains the Figure/Axes/Axis hierarchy; this sheet exists because the stateful pyplot API and the object-oriented API use *different verbs for the same action* — the number one Matplotlib point-killer on paper. Claims verified on matplotlib (Agg backend).

## 1. Syntax Matrix - What Breaks vs. What Runs

| You want to set... | Stateful `plt.` form | Object-oriented `ax.` form | Fatal form |
| :--- | :--- | :--- | :--- |
| Title | `plt.title("T")` | `ax.set_title("T")` | `ax.title("T")` — `TypeError`; `ax.title` is a *Text object*, not a callable. |
| X label | `plt.xlabel("x")` | `ax.set_xlabel("x")` | `ax.xlabel("x")` — no such method. |
| Limits | `plt.xlim(0, 10)` | `ax.set_xlim(0, 10)` | `ax.xlim(0, 10)` — no such method. |
| Grid | `plt.grid(True)` | `ax.grid(True)` | (both valid — same verb) |
| Legend | `plt.legend()` | `ax.legend()` | (both valid) |
| Axis ticks | — | `ax.axis('off')` | `ax.axis_off()` — not a method; `ax.axis('off')` is the call. |

**The set- prefix rule:** on an `Axes` object, every decoration verb from pyplot grows `set_`: `set_title`, `set_xlabel`, `set_ylabel`, `set_xlim`, `set_ylim`, `set_xticks`. The pattern is regular — one rule replaces a table.

## 2. Exact Signatures and Positional Defaults

```python
fig, ax = plt.subplots()                        # ONE axes -> ax is a bare Axes
fig, axs = plt.subplots(1, 2)                   # -> 1D array: axs[0], axs[1]
fig, axs = plt.subplots(2, 2)                   # -> 2D array: axs[row, col]
ax.imshow(X, cmap='gray', vmin=0, vmax=255)     # 2D matrix rendering
ax.hist(a.ravel(), bins=256, range=(0, 256), density=True)
ax.axis('off')                                  # hide ticks and frame
plt.tight_layout()                              # spacing fix (module-level)
plt.show()                                      # render
```

`plt.subplot(nrows, ncols, index)` (the singular, state-based variant) uses a **1-based** index that walks the grid row by row — index runs from 1 to nrows*ncols.

## 3. Trap Deep-Dives

### 3.1 Subplot Array Dimensionality
`plt.subplots(1, 2)` returns a **1D** array — address it as `axs[0]`, `axs[1]`. `plt.subplots(2, 2)` returns a **2D** array — address it as `axs[row, col]`. Writing `axs[1]` on a 2x2 grid raises an IndexError-adjacent failure (`axs[1]` is a whole row of Axes, and calling `.set_title` on it fails). When unsure, flatten on paper: `axs = axs.ravel()` then index linearly — always safe.

### 3.2 The Grayscale Colormap Bug
`ax.imshow(gray_img)` without `cmap='gray'` renders in **viridis** (green-purple) — the Matplotlib default. Every grayscale image question must show `cmap='gray'` explicitly. Verified: the image's registered colormap defaults to viridis.

### 3.3 The Dynamic Range Stretching Bug
With `vmin`/`vmax` unset, Matplotlib linearly maps the array's own min to black and its own max to white. A dark image occupying [10, 40] renders 10 as pure black and 40 as pure white — noise is exaggerated, and two differently-restored images are *not comparable*. Anchor the display: `vmin=0, vmax=255`. The parent note's rule: "Always set vmin=0, vmax=255 for 8-bit images."

### 3.4 BGR vs. RGB on the Canvas
OpenCV hands you BGR; Matplotlib displays RGB. Channel-swapped faces look blue. One line fixes it before any display: `rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)` (full treatment in [[15.5. OpenCV Matrix Topology, Saturated Math & BGR Conventions]]).

## 4. Motor-Recall Code Templates

```python
import matplotlib.pyplot as plt
fig, axs = plt.subplots(1, 2, figsize=(10, 4))
axs[0].imshow(noisy, cmap='gray', vmin=0, vmax=255)
axs[0].set_title("Noisy Input")
axs[0].axis('off')
axs[1].imshow(restored, cmap='gray', vmin=0, vmax=255)
axs[1].set_title("Restored Output")
axs[1].axis('off')
plt.tight_layout()
plt.show()
```

## 5. Exam Question Archetypes

**Archetype — before/after panel:** "Plot a noisy image and its restored version side-by-side with titles and no axis ticks." The template in Section 4 is the full answer: `subplots(1, 2)`, both `ax.set_title(...)`, both `ax.axis('off')`, `cmap='gray'`, `vmin=0, vmax=255` on both panels so the two images are comparable.

## 6. Self-Audit Checklist

- [ ] Every `ax.` decoration uses the `set_` prefix; no `ax.title(...)` / `ax.xlabel(...)`.
- [ ] 2D grids indexed `axs[row, col]`; 1D grids indexed `axs[i]` (or `axs.ravel()` first).
- [ ] Every grayscale `imshow` carries `cmap='gray'`.
- [ ] Every 8-bit `imshow` carries `vmin=0, vmax=255`.
- [ ] OpenCV images passed through `COLOR_BGR2RGB` before display.
- [ ] Tick suppression uses `ax.axis('off')`.
