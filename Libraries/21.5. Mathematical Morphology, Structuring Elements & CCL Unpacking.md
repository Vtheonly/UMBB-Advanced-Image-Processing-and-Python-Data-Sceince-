## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Structuring element | `se = cv2.getStructuringElement(cv2.MORPH_RECT, (3, 3))` | `cv2.getStructuringElement(3, 3)` | Shape constant + (w, h) tuple — both required (the tuple is ANOTHER (x, y)-order parameter, see [[16.5. OpenCV Geometric Warping, ROI Slicing & (W,H) vs (Y,X)]]). |
| Primitives | `cv2.erode(bin, se, iterations=1)` / `cv2.dilate(...)` | `binary.erode(...)` | Anti-object rule — no methods on image arrays. |
| Compound ops | `cv2.morphologyEx(bin, cv2.MORPH_OPEN, se)` | hand-rolling erode-then-dilate | Legal but slower to write; MORPH_OPEN / MORPH_CLOSE / MORPH_GRADIENT / MORPH_TOPHAT / MORPH_BLACKHAT exist. |
| CCL unpacking | `n, labels, stats, centroids = cv2.connectedComponentsWithStats(mask, connectivity=8)` | `labels = cv2.connectedComponentsWithStats(...)` | FOUR values — a single name captures the tuple and later `labels[i]` indexing behaves wrongly. |
| Object count | `n - 1` | `n` | Label 0 is the background: verified on a two-blob mask, `num_labels = 3`, objects = 2. |
| Stats access | `stats[i, cv2.CC_STAT_AREA]` | `stats['area']` | Integer columns via the five CC_STAT constants (0..4), never names. |
| Masks for morphology | uint8 {0, 255} frames | float / boolean arrays | OpenCV morphology validates 8-bit input. |
| SE shape flags | `cv2.MORPH_RECT` / `MORPH_CROSS` / `MORPH_ELLIPSE` | guessing `MORPH_CIRCLE` | ELLIPSE is the flag name (verified). |

## 2. Exact Signatures and Positional Defaults

```python
se = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))     # (w, h) tuple
er  = cv2.erode(bin_img, se, iterations=1)
di  = cv2.dilate(bin_img, se, iterations=1)
```

## 3. Trap Deep-Dives

### 3.1 Opening and Closing — the Order Contract
Opening = **erosion THEN dilation** (same SE): removes small foreground specks and thin isthmuses while roughly restoring object size. Closing = **dilation THEN erosion**: fills interior holes and narrow bays. Reverse the order in your answer and the described effect is the opposite one. Gradient = dilate minus erode = the boundary band.

### 3.2 The Four-Value Unpack and the Background Off-by-One
`connectedComponentsWithStats` returns `(num_labels, labels, stats, centroids)`.
- `num_labels` counts the background: **foreground objects = num_labels - 1** (verified: two blobs -> 3).
- `labels` is the per-pixel id map (same shape as the input).
- `stats` rows are `[x, y, w, h, area]` — the AABB origin plus area; the five `cv2.CC_STAT_*` constants index them (verified indices 0..4).
- `centroids` rows are $(\bar{x}, \bar{y})$ — Cartesian order again.

The noise-filtering archetype loops `for i in range(1, num_labels)` — starting at 1 drops the background without an extra condition.

### 3.3 Iterations Keyword
Erode/dilate accept `iterations=k` — k-fold application without loops. morphologyEx also takes it (the compound's inner steps repeat).

### 3.4 Structuring Element Geometry
`MORPH_RECT` = full block; `MORPH_CROSS` = plus-shaped N4 probe; `MORPH_ELLIPSE` = discretized disk. Arbitrary shapes (e.g., a 3x3 cross for `scipy.ndimage`) come from NumPy boolean arrays — see [[17.5. SciPy 2D Convolution Modes, Boundary Padding & Morphology]].

## 4. Motor-Recall Code Templates

```python
import cv2, numpy as np
_, bin_img = cv2.threshold(gray, 127, 255, cv2.THRESH_BINARY)
se = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))
clean = cv2.morphologyEx(bin_img, cv2.MORPH_OPEN, se)
n, labels, stats, cent = cv2.connectedComponentsWithStats(clean, connectivity=8)
count = sum(1 for i in range(1, n) if stats[i, cv2.CC_STAT_AREA] >= 30)
```
