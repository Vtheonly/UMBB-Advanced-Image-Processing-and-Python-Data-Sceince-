# 06.5. Pandas Series, DataFrame Structure & BlockManager Quirks

> Exam-defense companion to [[06. Pandas Structural Primitives - Series and DataFrame Architecture]]. The parent note explains the BlockManager; this sheet covers the single/double bracket rule, constructor keywords, index alignment, and NumPy extraction. Verified on pandas 2.2.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| One column | `df['Age']` | — | Returns a 1D **Series** (fine for analytics; fatal for Scikit-Learn input). |
| One column as matrix | `df[['Age']]` | `scaler.fit(df['Age'])` | Double brackets -> 2D DataFrame `(n, 1)`. The single-bracket Series makes estimators raise (`Expected a 2-dimensional container`). |
| Series constructor | `pd.Series(data, index=...)` | `pd.Series(index=..., data=...)` mixing keyword order | Keywords are safe any order; the trap is positional `pd.Series(index_values, data_values)` — first positional is always **data**. |
| DataFrame constructor | `pd.DataFrame(data, index=..., columns=...)` | `pd.DataFrame(index=..., columns=...)` with data omitted | Missing `data` yields an empty shell. |
| Raw NumPy extraction | `df['Col'].values` or `df['Col'].to_numpy()` | — | Drops the index; `.array` keeps the Pandas ExtensionArray. |
| Aligned arithmetic | `df['A'] + s` (matching index) | `df['A'] + s` (mismatched index) | Not a crash — **silent NaN injection** at unmatched labels. |

## 2. Exact Signatures and Positional Defaults

```python
s = pd.Series([25, 28, 22], index=["Amel", "Sami", "Rania"], name="Age")
df = pd.DataFrame({"Name": ["Amel", "Sami"], "Age": [25, 28]},
                  index=["A", "B"], columns=["Name", "Age"])
series_1d  = df["Age"]          # Series
frame_2d   = df[["Age"]]        # DataFrame with one column
arr        = df["Age"].to_numpy()   # raw ndarray, no index
```

## 3. Trap Deep-Dives

### 3.1 The Double-Bracket Rule (1D vs 2D)
`df['Age']` is a Series; `df[['Age']]` is a `(n, 1)` DataFrame. Analysis calls (`.mean()`, `.plot()`) want the Series; **estimator calls want the DataFrame**. The rule generalizes: any list of columns inside one bracket — `df[['Age', 'Salary']]` — is the 2D selection syntax. Verified: `StandardScaler().fit(df['Age'])` raises; `fit(df[['Age']])` works (see [[23.5. Scikit-Learn Matrix Bridge, Reshaping & Estimator Lifecycle]]).

### 3.2 Index Alignment Silently NaNs
A Series added to a DataFrame column aligns **on labels**, not positions:

```python
df = pd.DataFrame({"Age": [25, 28, 22]}, index=["A", "B", "C"])
s  = pd.Series([1, 2, 3], index=["A", "B", "Z"])
df["Age"] + s        # rows A, B sum fine; row C and Z-position produce NaN
```

No exception is thrown — the grader sees `NaN` where a number should be. When you construct a Series to combine, either reuse the frame's index or reset both sides to positional arrays (`.to_numpy()`).

### 3.3 Keyword Names Are Part of the API
`pd.Series(data, index=...)`, `pd.DataFrame(data, index=..., columns=...)`. Positionally, the first argument is always the data; `index` and `columns` must be keywords on paper (guessing them as positional is a silent misalignment).
