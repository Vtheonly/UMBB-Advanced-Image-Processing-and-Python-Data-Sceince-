# 22.5. Objective Metrics - MSE, PSNR, SSIM & Zero-Division Defense

> Exam-defense companion to [[22. Objective Image Quality Assessment - MSE, PSNR, and SSIM Metrics]]. Verified numerically (NumPy 2.1.3): the reference pair `[[250,10],[240,5]]` vs `[[200,10],[240,5]]` gives MSE = 625 and PSNR = 20.17 dB — use these as your hand-check anchors.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Squared difference | `diff ** 2` | `diff ^ 2` | `^` is bitwise XOR: `250 ^ 2 = 248` (verified) — a SILENT wrong value, no exception. |
| Decibel log | `np.log10(x)` / `math.log10(x)` | `np.log(x)` | Natural log understates PSNR by the factor $\ln 10 \approx 2.3026$ (verified) — every score wrong, no exception. |
| MSE input | `a.astype(np.float64) - b.astype(np.float64)` | `a - b` on uint8 | Modulo wrap corrupts signed differences BEFORE squaring — MSE meaningless. |
| Zero MSE | `if mse == 0.0: return float('inf')` | bare division | Identical images -> division by zero (inf with a warning at best, crash in strict contexts). |
| Range constant | `255.0` for uint8, `1.0` for float images | mixing them | PSNR shifts by $20\log_{10}(255) \approx 48.13$ dB. |
| Shape guard | `if a.shape != b.shape: raise ValueError` | assuming equal shapes | Misaligned metrics average over broadcast garbage. |

## 2. Exact Signatures and the Canonical Pair

```python
import numpy as np

def calculate_mse(original, distorted):
    if original.shape != distorted.shape:
        raise ValueError("Image matrices must have identical dimensions.")
    diff = original.astype(np.float64) - distorted.astype(np.float64)
    return float(np.mean(diff ** 2))                      # ** NOT ^

def calculate_psnr(original, distorted, max_val=255.0):
    mse = calculate_mse(original, distorted)
    if mse == 0.0:
        return float("inf")                               # identical images
    return float(10.0 * np.log10((max_val ** 2) / mse))   # log10 NOT log
```

## 3. Trap Deep-Dives

### 3.1 The Three Silent Killers
`^` instead of `**` (XOR), `log` instead of `log10` (natural log), and raw uint8 subtraction (modulo wrap) all produce **plausible-looking wrong numbers** — no interpreter would ever warn you, and that is precisely why they dominate paper-exam loss. Write `** 2` and `log10` and the float cast, then re-read those three tokens before moving on.

### 3.2 The Formula and Its Anchors
$$\text{PSNR} = 10 \cdot \log_{10}\left(\frac{R^2}{\text{MSE}}\right), \quad R = 255 \text{ (uint8)}$$
Hand-check anchors (verified): MSE 625 -> PSNR 20.17 dB; the identity $20\log_{10}(255) \approx 48.13$ gives PSNR $= 48.13 - 10\log_{10}(\text{MSE})$ for fast mental arithmetic. Typical band: 30-45 dB good restoration, below 20 dB severe corruption.

### 3.3 The Zero-Division Guard
Identical inputs make MSE exactly 0 and the fraction undefined. The defensible answer is $+\infty$ (perfect reconstruction) returned BEFORE the division — a one-branch guard, not a try/except.

### 3.4 Why Saturated Ops Are Forbidden in Metrics
`cv2.subtract` clamps signed differences to 0 — a +50 error and a -50 error both become 0 before squaring, and MSE collapses. Metric math runs exclusively on the float64 sandwich; saturation is for display blending (see [[15.5. OpenCV Matrix Topology, Saturated Math & BGR Conventions]]).

### 3.5 SSIM's Regularization Constants
The standard form uses $C_1 = (0.01 R)^2$, $C_2 = (0.03 R)^2$ with $R = 255$ — they exist to stop division-by-zero in flat regions (the structural-contrast denominator). State them when the question asks for SSIM "without high-level metric libraries"; the windowed mean is the global simplification used in the parent note.

## 5. Exam Question Archetypes

**Archetype — full PSNR function:** "Write a complete Python function to compute PSNR between two images without using high-level metric libraries." Section 2's pair, verbatim — shape guard, float cast, zero guard, log10, `**`.

**Archetype — arithmetic cross-check:** "A single pixel differs by 50 (250 -> 200) in a 2x2 image. Compute MSE and PSNR." MSE = $50^2 / 4 = 625$; PSNR = $10\log_{10}(65025/625) = 10\log_{10}(104.04) \approx 20.17$ dB (verified).

## 6. Self-Audit Checklist

- [ ] Zero `^` operators; every square is `** 2`.
- [ ] Every logarithm is `log10` (NumPy or math).
- [ ] Both operands cast to float64 before subtraction.
- [ ] The `mse == 0.0 -> inf` branch precedes the division.
- [ ] `max_val` stated per dtype (255 uint8 / 1.0 float).
- [ ] Shape equality checked before any arithmetic.
