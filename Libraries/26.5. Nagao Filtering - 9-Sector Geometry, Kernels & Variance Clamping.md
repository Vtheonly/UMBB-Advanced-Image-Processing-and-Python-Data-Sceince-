## 2. The 9-Sector Geometry (offset sets, ready to transcribe)

Window radius 2; offsets $(dy, dx)$ relative to the center:

```text
R0 cross (5):  (0,0) (+-1,0) (0,+-1)
R1 north (7):  (0,0) (-1,0) (-2,0) (-1,-1) (-2,-1) (-1,+1) (-2,+1)
R2 south (7):  (0,0) (+1,0) (+2,0) (+1,-1) (+2,-1) (+1,+1) (+2,+1)
R3 east  (7):  (0,0) (0,+1) (0,+2) (-1,+1) (-1,+2) (+1,+1) (+1,+2)
R4 west  (7):  (0,0) (0,-1) (0,-2) (-1,-1) (-1,-2) (+1,-1) (+1,-2)
R5 NE (7):     (0,0) (-1,0) (-1,+1) (-1,+2) (-2,+1) (-2,+2) (0,+1)
R6 NW (7):     (0,0) (-1,0) (-1,-1) (-1,-2) (-2,-1) (-2,-2) (0,-1)
R7 SE (7):     (0,0) (+1,0) (+1,+1) (+1,+2) (+2,+1) (+2,+2) (0,+1)
R8 SW (7):     (0,0) (+1,0) (+1,-1) (+1,-2) (+2,-1) (+2,-2) (0,-1)
```

Hardcoded mask construction: `MASKS[k, dy + 2, dx + 2] = 1.0`, then `MEAN_KERNELS = MASKS / MASKS.sum(axis=(1, 2))[:, None, None]` — normalized to act as mean kernels (verified sizes [5,7,7,7,7,7,7,7,7]).

## 3. Trap Deep-Dives

### 3.1 Selection and Output (the 3-line contract)
Per pixel: compute $\sigma_k^2$ for all nine sectors; $k^* = \arg\min_k \sigma_k^2$; output $\text{round}(\mu_{k^*})$. Variance flags edge-straddling sectors (two intensity populations -> large spread); at least one sector always lies along one side of the edge, so the average runs ALONG the contour. Worked example (verified): the vertical-edge 5x5 window of the parent note selects R4 (west bar) with variance 1.061 among competitors > 1000; output 90 — while the plain 5x5 box mean would have been 126.56 (a +36.6 shift).

### 3.2 The Variance Identity and Its Clamp
$$\sigma_k^2 = E[X^2] - (E[X])^2$$
Both moments are convolutions of the image (and its square) with the normalized mask — the key that collapses 61 gathers per pixel into 18 `filter2D` calls. The identity in float64 can produce $-10^{-13}$ when the sector is exactly flat (catastrophic cancellation of nearly equal large numbers); clamp: `np.maximum(sq - means**2, 0.0)`. When two sectors' variances are mathematically TIED, this rounding noise — not your logic — decides the winner; for grading reproducibility, round before comparing (`np.round(var, 6)`), which the parent note prescribes.

### 3.3 The Border Dialect (the rim pitfall)
`np.pad(img, 2, mode='reflect')` == `cv2.BORDER_REFLECT_101` (no edge repeat); `np.pad(..., mode='symmetric')` == `cv2.BORDER_REFLECT` (edge repeated). Verified array-equal. All four implementations of the parent note standardize on REFLECT_101/reflect precisely so their outputs agree pixel-for-pixel; answer any "which padding?" question with that pairing.

### 3.4 Float64 or Bust
The squared-image plane $f \cdot f$ reaches 65025 — far beyond uint8's 255. Cast BEFORE squaring, and keep the (9, H, W) statistic planes in float64; cast only the final chosen mean through the round/clip/astype sandwich.

## 4. Motor-Recall Code Templates

```python
import numpy as np, cv2
padded = np.pad(img.astype(np.float64), 2, mode="reflect")   # = BORDER_REFLECT_101
# Explicit loop core:
best_var, best_mean = np.inf, padded[py, px]
for region in SUB_REGIONS:
    vals = [padded[py + dy, px + dx] for dy, dx in region]
    var = np.var(vals)                       # biased estimator (divide by |R|)
    if var < best_var:                        # strict <: first-wins ties
        best_var, best_mean = var, np.mean(vals)
out[y, x] = int(round(best_mean))
# Fast convolution core:
means = np.stack([cv2.filter2D(f, -1, MEAN_KERNELS[k], borderType=cv2.BORDER_REFLECT_101) for k in range(9)])
sq    = np.stack([cv2.filter2D(f * f, -1, MEAN_KERNELS[k], borderType=cv2.BORDER_REFLECT_101) for k in range(9)])
variances = np.maximum(sq - means ** 2, 0.0)  # clamped one-pass variance
k_star = np.argmin(variances, axis=0)         # first-sector tie-breaking
chosen = np.take_along_axis(means, k_star[None], axis=0)[0]
```
