## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Why the wrong form fails |
| :--- | :--- | :--- | :--- |
| A 2D zero buffer | `np.zeros((10, 10))` | `np.zeros(10, 10)` | `TypeError` — the second loose argument is parsed as a `dtype`, not a second dimension. Shape arguments for `zeros`/`ones`/`full`/`empty` travel **inside one tuple**. |
| An array from values | `np.array([1, 2, 3])` | `np.array(1, 2, 3)` | `TypeError` — `np.array` takes ONE positional object; wrap the values in a list (or nested lists for 2D). |
| Shape probe | `img.shape` | `img.shape()` | `TypeError` — `shape`, `dtype`, `ndim`, `size`, `nbytes`, `strides` are attributes (struct fields), never methods. |
| Type probe | `img.dtype` | `img.dtype()` | Same attribute rule. |
| Sequence, stop exclusive | `np.arange(0, 10, 2)` | expecting `10` inside | `arange` **excludes** the stop: gives `[0, 2, 4, 6, 8]`. |
| Sequence, stop inclusive | `np.linspace(0, 1, 5)` | expecting `1` excluded | `linspace` **includes** both endpoints: `[0.0, 0.25, 0.5, 0.75, 1.0]`. |
| Float cast | `img.astype(np.float64)` | `img.astype(np.float64)` alone on a line | `.astype` **returns a new array**; without assignment the cast evaporates. The original `uint8` buffer is untouched. |
| Buffer clone | `arr.copy()` | `np.copy` without parentheses | `copy` is a method: call it, assign the result. |

## 2. Exact Signatures and Positional Defaults

```python
np.zeros(shape_tuple, dtype=float)        # np.zeros((H, W))          tuple!
np.ones(shape_tuple, dtype=float)        # np.ones((3, 2))
np.full(shape_tuple, fill_value)         # np.full((2, 2), 7)
np.empty(shape_tuple)                     # uninitialized garbage bytes (fast, not zero)
np.eye(N)                                 # N x N identity; np.identity(N) is the twin
np.arange(start, stop, step)              # stop EXCLUSIVE
np.linspace(start, stop, num=50)          # stop INCLUSIVE
np.array(object)                          # object = list / nested list / tuple
```

**The tuple/scalar split, memorized:** constructors that take a *shape* (`zeros`, `ones`, `full`, `empty`, `eye`) want a shape **tuple**. Constructors that take *contents* (`array`, `fromiter`) want a **sequence of values**. `np.random.rand(H, W)` is the exception on the NumPy side: loose integers (see [[04.5. NumPy Math Engine, Broadcasting Rules & Axis Reductions]]).

## 3. Trap Deep-Dives

### 3.1 The Allocation Tuple Trap
`np.zeros(10, 10)` does not create a 10x10 matrix. Python hands the second `10` to the `dtype` slot, so NumPy raises `TypeError: Cannot interpret '10' as a data type`. One missing pair of parentheses is a full point deduction on paper. When the shape comes from an image, never rebuild the tuple by hand:

```python
buffer = np.zeros_like(img)                        # copies shape AND dtype in one call
buffer = np.zeros(img.shape, dtype=img.dtype)     # the explicit equivalent
```

`np.zeros_like` is the exam-safe archetype: "Pre-allocate a zero buffer matching an image's dimensions and type without hardcoding numbers."

### 3.2 Attribute vs. Method (the Parentheses Trap)
Attributes are *state*; methods are *actions*. Writing `img.shape()` adds a call to something that is not callable — instant `TypeError`. The full attribute list worth memorizing: `shape`, `dtype`, `ndim`, `size`, `itemsize`, `nbytes`, `strides`, `T` (see [[05.5. NumPy Linear Algebra, Matrix Products & Solvers]] for `.T`).

### 3.3 astype Returns a New Buffer
`.astype(np.float64)` **never mutates in place**. This is the opening move of the Float-to-Int Defensive Sandwich of [[19.5. Spatial Restoration, Integral Fast Filtering & Noise Generators]]:

```python
work = img.astype(np.float64)      # 1. capture the returned float buffer
processed = work - 50.0            # 2. compute on it
out = np.clip(np.round(processed), 0, 255).astype(np.uint8)   # 3. cast back, assigned
```

### 3.4 arange vs. linspace Boundaries
`np.arange(0, 256, 1)` yields 0..255 (256 values, stop dropped). `np.linspace(0, 255, 256)` also yields 0..255 (endpoints kept). They agree only because the arithmetic lines up; the *convention* differs. On paper, annotate which one you chose — graders check boundary logic.

## 4. Motor-Recall Code Templates

```python
import numpy as np
buf = np.zeros_like(img)                          # matching buffer, one call
grid = np.zeros((h, w), dtype=np.uint8)           # explicit tuple allocation
seq = np.arange(0, 256, 1)                        # stop EXCLUSIVE
pts = np.linspace(0.0, 1.0, 5)                    # stop INCLUSIVE
f = img.astype(np.float64)                         # astype RETURNS - always assign
```

## 5. Exam Question Archetypes

**Archetype 1 — matching buffer:** "Pre-allocate a zero buffer matching an image's dimensions and type without hardcoding numbers."
```python
out = np.zeros_like(img)
```

**Archetype 2 — sequence boundaries:** "Generate all even gray levels 0..254 inclusive."
```python
levels = np.arange(0, 256, 2)      # 0..254: stop 256 excluded, step 2 -> 128 values
```

**Archetype 3 — float hygiene:** "Why does `img.astype(np.float64)` on its own line not convert the image?"
Because `.astype` returns a *new* array; the statement's result is discarded. Correct: `img = img.astype(np.float64)` — or better, bind a new name so the original stays available.

## 6. Self-Audit Checklist

- [ ] Every `zeros` / `ones` / `full` shape argument is wrapped in `( )` as a single tuple.
- [ ] No `.shape()`, `.dtype()`, `.ndim()`, `.size()` anywhere — attributes are bare.
- [ ] Every `.astype(...)` result is assigned to a variable.
- [ ] `arange` stops are exclusive; `linspace` stops are inclusive — boundary noted in a comment.
- [ ] Buffers derived from images use `zeros_like` or `img.shape`, not hand-copied numbers.
