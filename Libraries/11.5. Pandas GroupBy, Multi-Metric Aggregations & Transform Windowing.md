# 11.5. Pandas GroupBy, Multi-Metric Aggregations & Transform Windowing

> Exam-defense companion to [[11. Pandas Grouping, Split-Apply-Combine, and Statistical Aggregations]]. Verified on pandas 2.2.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Group summary | `df.groupby('City')['Salary'].mean()` | `df.groupby('City')['Salary'].mean` | Method without parentheses — the object, not the result. |
| Named aggregation | `df.groupby('Dept').agg(AvgCost=('Cost','mean'))` | `df.groupby('Dept').agg({'Cost': 'mean'}, Avg=...)` mixing styles | One style per call: either a dict `{'col': 'func'}` or named tuples `Name=('col', 'func')` — not both. |
| Broadcast statistic | `df['DeptAvg'] = df.groupby('Dept')['Salary'].transform('mean')` | `df['DeptAvg'] = df.groupby('Dept')['Salary'].mean()` then assign | The `.mean()` result is indexed by GROUP, not by row — assigning it to a column misaligns and fills NaN. |
| Contingency table | `pd.crosstab(df['Dept'], df['Risk'])` | `df.crosstab(...)` | `AttributeError` — crosstab is a top-level `pd.` function (same family as `get_dummies`). |
| Multi-key grouping | `df.groupby(['Dept', 'City'])` | `df.groupby('Dept', 'City')` | Two positional strings are read as (by, level-ish) — wrap the keys in ONE list. |

## 2. Exact Signatures and Positional Defaults

```python
avg = df.groupby("City")["Salary"].mean()               # Series indexed by group keys
summary = df.groupby("Dept").agg(                       # named aggregation:
    AvgCost=("Cost", "mean"),                           #   NewName = (column, func)
    MaxCost=("Cost", "max"),
    TotalPatients=("ID", "count"),
).reset_index()                                         # keys back as columns
df["DeptAvgSalary"] = df.groupby("Dept")["Salary"].transform("mean")
contingency = pd.crosstab(df["Dept"], df["RiskCategory"])
df["SalaryDiff"] = df["Salary"] - df.groupby("Dept")["Salary"].transform("mean")
```

## 3. Trap Deep-Dives

### 3.1 agg vs. transform — the Shape Question
`.agg(...)` **collapses**: one output row per group (the DataFrame changes shape). `.transform('mean')` **broadcasts**: the group statistic is repeated down every original row, preserving shape. The one-line test on paper: "must the output align with the source rows?" — then it is `transform`. Verified: `transform('mean')` on a 3-row frame returns 3 rows; `.agg` returns one row per group.

### 3.2 The Assignment Misalignment Trap
`df.groupby('Dept')['Salary'].mean()` is indexed by department — assigning it as a column aligns on the row index and yields NaN. The broadcasting assignment MUST go through `.transform(...)`. This is the blueprint archetype: "difference between each employee's salary and their department's average."

### 3.3 reset_index After Named Aggregation
Named aggregation returns the group keys as the index. `.reset_index()` promotes them to regular columns — the tidy shape later chapters (and `sns.barplot(data=...)`) expect.

### 3.4 crosstab Is Top-Level
`pd.crosstab(a, b)` — the counting counterpart of groupby — always called on `pd`, never on the frame. It equals `df.groupby([a, b]).size().unstack()` in spirit.

import pandas as pd
city_avg = df.groupby("City")["Salary"].mean()                     # collapse

## 5. Exam Question Archetypes

**Archetype — salary vs. department average:** "Calculate the difference between each employee's salary and their department's average salary."
```python
df["DeptAvg"] = df.groupby("Dept")["Salary"].transform("mean")
df["SalaryDiff"] = df["Salary"] - df["DeptAvg"]
```

**Archetype — multi-metric table:** "Per department: average cost, maximum cost, patient count."
```python
out = df.groupby("Dept").agg(
    AvgCost=("Cost", "mean"),
    MaxCost=("Cost", "max"),
    TotalPatients=("ID", "count"),
).reset_index()
```

## 6. Self-Audit Checklist

- [ ] Every group-reduction call ends in `()` — method, not attribute.
- [ ] `.agg` in one consistent style; named tuples preferred (self-documenting).
- [ ] Every broadcast statistic goes through `.transform(...)`.
- [ ] `crosstab` called on `pd.`, group keys inside one list.
