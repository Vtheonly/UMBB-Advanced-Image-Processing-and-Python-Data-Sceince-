# 14.5. Pandas Temporal Mechanics, DatetimeIndex & Rolling Windows

> Exam-defense companion to [[14. Pandas Temporal Mechanics - Time Series and Datetime Calculations]]. Verified on pandas 2.2.3 — including one live deprecation that changes what you should write on paper.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Parsing dates | `pd.to_datetime(df['Date'])` | `df['Date'].to_datetime()` | `AttributeError` — `to_datetime` is a top-level `pd.` function. |
| Year of a Series | `df['Date'].dt.year` | `df['Date'].year` | `AttributeError` — Series members are reached only through the `.dt` accessor (verified). Nuance: a bare `DatetimeIndex` DOES expose `.year` directly — the accessor is for Series/columns. |
| Month name | `df['Date'].dt.month_name()` | `df['Date'].dt.monthname()` | The method is `month_name()`; `.strftime('%b')` is the format-string twin. |
| Date sequence | `pd.date_range(start='2025-01-01', periods=12, freq='MS')` | `freq='M'` expecting month starts | `M`/`ME` is month END; `MS` is month START. |
| Quarterly bucket | `s.resample('QE').sum()` | `s.resample('Q')` | `Q` is **deprecated in pandas 2.2+** (verified DeprecationWarning); write `QE` on paper. |
| Moving average | `s.rolling(window=3).mean()` | — | Preserves row count; first `window-1` entries are NaN. |
| Lag | `s.shift(1)` | — | Values move DOWN; leading slot NaN. |
| Growth | `s.pct_change() * 100` | manual `(s - s.shift(1)) / s.shift(1)` | Both correct — `pct_change()` is the library spelling. |

## 2. Exact Signatures and Positional Defaults

```python
df["Date"] = pd.to_datetime(df["Date"])           # top-level parse
df["Year"] = df["Date"].dt.year                   # Series .dt accessor
df["Month"] = df["Date"].dt.month_name()
df["Date"].dt.strftime("%b")                      # formatted labels
idx = pd.date_range(start="2026-01-01", periods=12, freq="MS")   # Month Start
q = df["Sales"].resample("QE").sum()              # quarterly buckets (2.2+)
sma = df["Sales"].rolling(window=3).mean()         # 3-period moving average
lag = df["Sales"].shift(1)                          # prior period
growth = df["Sales"].pct_change() * 100            # percent change
```

## 3. Trap Deep-Dives

### 3.1 The .dt Accessor Rule
A datetime column behaves like strings and `.str`: reach members through `.dt` — `.dt.year`, `.dt.month`, `.dt.day`, `.dt.day_name()`, `.dt.month_name()`, `.dt.strftime(fmt)`. Calling `.year` on the Series raises. (The exception: a free-standing `DatetimeIndex` object exposes `.year` directly — if your code wrote `idx.year` and it worked, you were holding an index, not a Series.)

### 3.2 resample vs. rolling — the Collapse Question
`resample('QE')` **re-buckets** time into quarterly groups and collapses to one row per bucket (aggregate semantics: `sum`, `mean`, `max`). `rolling(window=3)` slides over consecutive rows and **preserves** every row (smooth semantics). Verified: `resample('QE').sum()` on 4 monthly rows -> 2 quarters; `rolling(3).mean()` on 4 rows -> 4 rows with 2 leading NaN. The exam question "compute a 3-month moving average" is always rolling.

### 3.3 The 'Q' to 'QE' Migration (live errata)
pandas 2.2 deprecated single-letter quarter aliases: `'Q'` -> `'QE'` (quarter end), `'Q'` -> `'QS'` (quarter start). The parent vault note 14 still shows `resample('Q')` — it emits a DeprecationWarning today and will break on future pandas. Write `'QE'`/`'QS'` and add a comment; same family: `'M'` -> `'ME'` (month end) with `'MS'` unaffected.

### 3.4 shift(1) Feeds pct_change
`pct_change()` is exactly `(s - s.shift(1)) / s.shift(1)` — the library call is preferred, but knowing the expansion lets you answer the "write it from scratch" variant. Month-over-month percent growth: `df['GrowthPct'] = df['Sales'].pct_change() * 100`.

## 4. Motor-Recall Code Templates

```python
import pandas as pd
df["Date"] = pd.to_datetime(df["Date"])          # pd. top-level
df["Year"] = df["Date"].dt.year                   # .dt accessor on Series
df.index = pd.date_range(start="2026-01-01", periods=12, freq="MS")
df["SMA3"] = df["Sales"].rolling(window=3).mean()  # rows preserved
df["Prev"] = df["Sales"].shift(1)
df["GrowthPct"] = df["Sales"].pct_change() * 100
quarterly = df["Sales"].resample("QE").sum()       # rows collapse (2.2+ spelling)
```

## 5. Exam Question Archetypes

**Archetype — moving average + growth:** "Compute a 3-month rolling moving average of sales and determine month-over-month percentage growth."
```python
df["SMA3"] = df["Sales"].rolling(window=3).mean()
df["GrowthPct"] = df["Sales"].pct_change() * 100
```

**Archetype — accessor pop-quiz:** "Why does `df['Date'].year` crash while `date_index.year` runs?" The Series gates temporal members behind `.dt`; the DatetimeIndex exposes them directly.

## 6. Self-Audit Checklist

- [ ] `to_datetime` called on `pd.`, never on the frame.
- [ ] Every Series temporal member reached through `.dt`.
- [ ] Resample aliases spelled `QE`/`QS`/`MS`/`ME` (pandas 2.2+); no bare `Q` or `M`.
- [ ] "Moving average" answered with `rolling`, "quarterly totals" with `resample`.
- [ ] `shift(1)` result NaN-headed — first-row growth is NaN by construction.
