## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Safe numeric coercion | `pd.to_numeric(df['Col'], errors='coerce')` | `df['Col'].astype(int)` on a column holding `'abc'`/`NaN` | `ValueError` — `astype(int)` cannot parse invalid tokens or NaN; `to_numeric` converts them to `NaN` instead of dying. |
| CSV export | `df.to_csv('out.csv', index=False)` | `df.to_csv('out.csv')` | Not a crash: the next `read_csv` grows an `Unnamed: 0` column. Verified reproductions show the phantom column appearing exactly when the flag is omitted. |
| Column projection at load | `pd.read_csv(f, usecols=['A','B'], index_col='A')` | `usecols=('A', 'B')` tuple | Tuples are accepted but a lone string is not a projection list — keep the list bracket habit. |
| Null audit | `df.isnull().sum()` | `df.isnull()` alone | The bare call returns the boolean mask; `.sum()` per column is the actual audit. |
| Dtypes listing | `df.dtypes` | `df.dtypes()` | Attribute, not method. |
| Memory audit | `df.info()` | — | Method; prints dtypes, non-null counts, RAM. |

## 2. Exact Signatures and Positional Defaults

```python
df = pd.read_csv("dataset.csv", sep=",", encoding="utf-8",
                 usecols=["PatientID", "Age"], index_col="PatientID")
df.to_csv("cleaned.csv", index=False)
df.to_excel("report.xlsx", index=False)        # openpyxl required
df.info()                                      # structural + memory audit
df.isnull().sum()                              # per-column NaN counts
df.describe()                                  # numeric summaries
df.select_dtypes(include="number")              # dtype-based subsetting
pd.to_numeric(df["Age"], errors="coerce")      # invalid -> NaN
df["Age"].fillna(0).astype(int)                # only AFTER nulls resolved
```

## 3. Trap Deep-Dives

### 3.1 astype(int) on Real-World Columns
A column scraped from a file usually contains `NaN` or text. `astype(int)` raises `ValueError: cannot convert float NaN to integer` (or chokes on the string). The pipeline order is fixed: **coerce first, fill/ drop second, cast last**:
```python
df["Age"] = pd.to_numeric(df["Age"], errors="coerce")   # 1. corrupt -> NaN
df["Age"] = df["Age"].fillna(df["Age"].median())        # 2. resolve NaN
df["Age"] = df["Age"].astype(int)                        # 3. now safe
```

### 3.2 The Unnamed: 0 Ghost Column
Exporting with the index writes a leading position column; re-loading returns it as `Unnamed: 0`. Any later `pd.merge` on column names then fails to find the join key. `index=False` on export — or `index_col=0` on load — kills the ghost.

### 3.3 Projections During Ingestion
`usecols` lowers memory before the frame is built; `index_col` avoids a later `set_index`. Both are load-time keywords on `read_csv` — they do not exist on the frame after the fact.

## 5. Exam Question Archetypes

**Archetype — corrupted numeric column:** "Load a dataset, inspect the memory footprint, and parse a corrupted numeric column containing string errors."
```python
df = pd.read_csv("dataset.csv")
df.info()                                          # shape, dtypes, RAM footprint
df["Dose"] = pd.to_numeric(df["Dose"], errors="coerce")   # 'error' -> NaN
```

## 6. Self-Audit Checklist

- [ ] Every `astype(int)` is preceded by `to_numeric(errors='coerce')` plus a NaN strategy.
- [ ] Every `to_csv` carries `index=False` unless the index is intentional data.
- [ ] Null audits written as `.isnull().sum()` — the mask alone is not the audit.
- [ ] `dtypes` / `columns` / `shape` bare (attributes); `info` / `describe` called.
