# 15. Interactive Visualization and Geospatial Mapping - Plotly and Cartopy

## 1. Overview
This note covers interactive plotting and geospatial visualizations using Plotly and Cartopy.

## 2. Interactive Visualizations with Plotly Express
Plotly generates web-ready, interactive JavaScript visualizations directly from Pandas DataFrames, allowing users to hover over data points, pan, and zoom:

```python
import plotly.express as px

# Generate an interactive scatter plot
fig = px.scatter(
    df, 
    x="Age", 
    y="Cholesterol", 
    color="Diagnosis", 
    size="BloodPressure", 
    hover_data=["PatientID"],
    title="Interactive Patient Health Distribution"
)
fig.show()
```

## 3. Geospatial Mapping with Cartopy
Cartopy is the modern successor to Basemap, providing coordinate reference systems (CRS) and map projections built on top of Matplotlib:

```python
import matplotlib.pyplot as plt
import cartopy.crs as ccrs
import cartopy.feature as cfeature

fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(1, 1, 1, projection=ccrs.PlateCarree())

# Set geographic display bounds [lon_min, lon_max, lat_min, lat_max] (Focus: Algeria)
ax.set_extent([-2, 10, 32, 38], crs=ccrs.PlateCarree())

# Add geographic boundaries
ax.add_feature(cfeature.LAND, facecolor="lightgray")
ax.add_feature(cfeature.COASTLINE, linewidth=1.0)
ax.add_feature(cfeature.BORDERS, linestyle=":")

# Plot regional coordinates (Algiers, Oran, Annaba)
cities = {"Algiers": (3.0588, 36.7538), "Oran": (-0.6417, 35.6987), "Annaba": (7.7667, 36.9000)}
for name, (lon, lat) in cities.items():
    ax.plot(lon, lat, marker="o", color="crimson", markersize=6, transform=ccrs.Geodetic())
    ax.text(lon + 0.2, lat, name, transform=ccrs.Geodetic(), fontsize=10)

ax.set_title("Regional Healthcare Cohort Distribution", fontweight="bold")
plt.show()
```
