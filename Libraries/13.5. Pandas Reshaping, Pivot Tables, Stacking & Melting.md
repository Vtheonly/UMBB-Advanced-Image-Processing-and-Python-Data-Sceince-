# 13.5. Pandas Reshaping, Pivot Tables, Stacking & Melting

> Exam-defense companion to [[13. Pandas Data Reshaping - Pivoting, Unpivoting, Stacking, and Melting]]. Verified on pandas 2.2.3.

## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Pivot (unique pairs) | `df.pivot(index='City', columns='Dept', values='Cost')` | — | Works only when (index, columns) pairs are unique. |
| Pivot with duplicates | `df.pivot_table(index='City', columns='Dept', values='Cost', aggfunc='mean')` | `df.pivot(...)` on duplicate pairs | `ValueError: Index contains duplicate entries` (verified) — `pivot_table` aggregates duplicates instead. |
| Unpivot | `df.melt(id_vars=['Name'], value_vars=['Q1','Q2'], var_name='Quarter', value_name='Sales')` | `pd.melt(df, ...)` only | `pd.melt` is the legacy top-level twin; `df.melt(...)` is the instance method to write. |
| Sort | `df.sort_values(by='Cost', ascending=False)` | `df.sort_values(by='Cost', reverse=True)` | `reverse` is the built-in `sorted`/`list.sort` keyword — Pandas rejects it (verified TypeError). |
| Python sort | `sorted(df['Cost'], reverse=True)` | mixing into DataFrame calls | Different universe: `sorted` works on iterables, returns a list. |

## 2. Exact Signatures and Positional Defaults

```python
piv = df.pivot_table(index="City", columns="Department",
                     values="Cost", aggfunc="mean")          # aggfunc default 'mean'
long = df.melt(id_vars=["Name", "City"], value_vars=["Q1", "Q2"],
               var_name="Quarter", value_name="Sales")
top = df.sort_values(by="Cost", ascending=False)
```

## 3. Trap Deep-Dives

### 3.1 pivot vs. pivot_table
`pivot` is the dumb reshaper: one value per (index, column) cell or it dies. `pivot_table` is the aggregating reshaper: duplicates collapse through `aggfunc` (default `mean`; `sum`, `count`, `max` available; `fill_value=` patches the NaN holes of absent combinations). Exam heuristic: if the source table has repeated (row-key, col-key) pairs — or the question says "average salary per city per department" — it is `pivot_table`.

### 3.2 melt's Four Keywords
`id_vars` stay fixed as identifiers; `value_vars` get stacked into the new long column; `var_name` names the label column; `value_name` names the value column. Omitting `var_name`/`value_name` yields the defaults `variable`/`value` — graders deduct for unnamed long frames.

### 3.3 sort_values Vocabulary
`by=` (one column or a list), `ascending=` (scalar or list — per-key), `kind=` for the algorithm. `reverse=` is not in the vocabulary; descending order is `ascending=False`. For a top-N slice, chain `.head(n)`.

## 4. Motor-Recall Code Templates

```python
import pandas as pd
piv = df.pivot_table(index="City", columns="Dept", values="Cost", aggfunc="mean")

```

## 5. Exam Question Archetypes

**Archetype — wide to long:** "Reshape a wide quarterly sales table into a long format suitable for Seaborn line plotting."
```python
sales_long = df.melt(id_vars=["Region"], value_vars=["Q1", "Q2", "Q3", "Q4"],
                     var_name="Quarter", value_name="Sales")
```

**Archetype — summary matrix:** "Average salary per city per department, NaN where absent."
```python
matrix = df.pivot_table(index="City", columns="Department",
                        values="Salary", aggfunc="mean")
```

## 6. Self-Audit Checklist

- [ ] Duplicate (index, columns) pairs -> `pivot_table`, never `pivot`.
- [ ] `melt` carries all four keywords when the question names its output columns.
- [ ] Descending sorts use `ascending=False` — no `reverse=`.
- [ ] `aggfunc` stated explicitly (default is `mean` even though nobody says so).
