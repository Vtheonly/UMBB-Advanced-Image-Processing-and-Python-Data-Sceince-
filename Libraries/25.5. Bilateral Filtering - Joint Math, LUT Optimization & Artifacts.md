## 2. The Formula Set (memorized as three lines)

$$I_{\text{bil}}(p) = \frac{1}{W_p} \sum_{q \in S} I(q)\, G_{\sigma_s}\big(\|p-q\|\big)\, G_{\sigma_r}\big(|I(p)-I(q)|\big), \qquad W_p = \sum_{q \in S} G_{\sigma_s}\,G_{\sigma_r}$$

$$G_{\sigma_s}(d) = \exp\left(-\frac{d^2}{2\sigma_s^2}\right), \qquad G_{\sigma_r}(\Delta) = \exp\left(-\frac{\Delta^2}{2\sigma_r^2}\right)$$

Explain every symbol when the question says "derive" or "justify": p target pixel, q neighbor, $\|p-q\|$ geometric distance, $|I(p)-I(q)|$ radiometric difference, $W_p$ the normalizer guaranteeing a proper weighted average.

## 3. Trap Deep-Dives

### 3.1 The Verified Worked Example (write these numbers)
1-D signal $[50, 52, 51, 150, 148]$, center at index 2, $\sigma_s = 1$, $\sigma_r = 25$:
- Plain Gaussian blur output: $80.65$ — error $+29.65$ (bright side contaminates the average).
- Bilateral output: $51.29$ — error $+0.29$. The 99-level and 97-level differences carry weights $0.00039$ and $0.00054$ ($\approx 2500\times$/$1900\times$ attenuation).
- Same edge, $\sigma_r \to \infty$: range kernel -> 1, output -> exactly the Gaussian $80.65$ (verified) — the degeneration sanity check.

### 3.2 Parameter Limits (both directions)
- $\sigma_r \to \infty$: degenerates into a plain linear Gaussian blur (verified: 80.65).
- $\sigma_r \to 0$: only identical intensities survive — identity filter, perfect edges, zero denoising.
- Practice: $\sigma_r$ sized to the noise sigma you want absorbed but well below the edge heights you keep: $\sigma_{\text{noise}} \lesssim \sigma_r \ll h_{\text{edge}}$; 8-bit starting range $\sigma_r \in [25, 75]$; d = 5..9 fine texture, >= 15 coarse blotches.

### 3.3 The Range LUT (the implementation trick)
For 8-bit images $|I(p) - I(q)| \in \{0, \dots, 255\}$ — all 256 possible range weights precompute in one line:
```python
range_lut = np.exp(-(np.arange(256) ** 2) / (2 * sigma_r ** 2))
# per pixel: Gr = range_lut[np.abs(patch - center)]
```
Verified: `lut[120] = 0.0111` for $\sigma_r = 40$, identical to the direct `np.exp` evaluation. One transcendental per DIFFERENCE VALUE, then pure array indexing — the trick OpenCV's C++ core itself uses (why `cv2.bilateralFilter` and the naive NumPy version agree to ~0.74 gray levels mean absolute difference).

### 3.4 Artifacts Vocabulary (short-answer ammunition)
- **Staircasing:** iteration turns smooth gradients into constant-value terraces.
- **Gradient reversal:** on ramps the output overshoots past the next plateau — the "cartoon outline" artifact.
- **Halos:** $\sigma_r$ too small vs. noise leaves high-variance fringes at strong edges.
- **Impulse noise NOT removed:** outlier differs from all neighbors — weights die, speckle persists; median pre-filter first.

## 4. Motor-Recall Code Templates

```python
import cv2, numpy as np
clean = cv2.bilateralFilter(img, 9, 75, 75)          # d, sigmaColor, sigmaSpace
# from-scratch core (per pixel):
Gs = np.exp(-(xx**2 + yy**2) / (2 * sigma_s**2))     # spatial kernel, precomputed
lut = np.exp(-(np.arange(256)**2) / (2 * sigma_r**2))# range LUT
Gr = lut[np.abs(patch - center).astype(np.uint8)]     # table lookup
out_px = (patch * Gs * Gr).sum() / (Gs * Gr).sum()    # normalized weighted average
```
